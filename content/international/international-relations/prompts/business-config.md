## 二、受众定位

- **受众**：国际关系研究者、涉外事务与合规团队、政策分析者。
- **视角**：以官方声明、条约文本与多边机制文件为主线，做事件—机制—影响解读。
- **结论边界**：只给框架性说明与可核验信息，**不构成外交、法律或安全建议**；不预测他国政策意图，不引用匿名消息。

## 三、术语口径区分（表格与正文中不得混用）

- **外交关系级别 ≠ 外交承认**：建交 / 代办级 / 大使级 / 断交须逐条核对官方表述。
- **制裁 ≠ 出口管制 ≠ 投资限制**：法律工具与适用对象不同，分列。
- **条约签署 ≠ 批准 ≠ 生效**：三阶段分列，附各自日期。
- **国际组织成员 ≠ 观察员 ≠ 对话伙伴**：地位与权利不同。
- **停火 ≠ 和平协议 ≠ 终战宣言**：法律效力不同。
- **声明 ≠ 联合公报 ≠ 行动计划**：约束力不同。

## 四、来源优先级（通用基座第四节的实例化，冲突时报双份并标注）

① **官方一手**：联合国（Digital Library / Treaty Collection / UN News / 各机构发布）、各国外交部与政府（中国外交部、美国务院、英国 FCDO、日本外务省、韩国外交部、欧盟 EEAS）、东盟 / 非盟 / 阿盟等区域组织官方站
＞ ② **行业机构**：国际危机组织（ICG）、Chatham House、IISS、CFR（仅作分析线索，不替代官方）
＞ ③ **挂牌门户 / 数据库**：UN Treaty Collection、UN Digital Library、World Bank WDI、各国官方统计
＞ ④ **媒体转述**：Reuters、Bloomberg、AP、各国主流媒体（须标「需核实原文」）

**机构获取优先级 P0–P5**：

| 层级 | 渠道 | 使用规则 |
|---|---|---|
| P0 | 官方声明 / 条约文本 / 官方公报 | 唯一可直接采信层，标「已核验」 |
| P1 | 官方 PDF / 会议纪要 / 决议文本 | 记录文件号、发布日期、页码 |
| P2 | 国际组织数据库 | 用于条约与席位状态快照 |
| P3 | 英文媒体 | 只用于发现线索；数值与措辞标「需核实原文」 |
| P4 | 智库与行业机构 | 交叉验证方向；不替代 P0 |
| P5 | 官方条约集 / 法律文本 | 最终裁决条约状态与效力口径 |

**最小可替代集**：UN Digital Library + 当事国外交部原文；结论置信度降为「方向高、幅度中、时点低」。

## 五、信号规则阈值（K01–K08，ex-ante 预校准）

> 本项目自设（非官方），属阈值预校准；首次中期回测 2027-06，标注口径见 `engine/templates/decision-delivery-spec.md` 第六节。运行前以 `{{REGISTRY_PATH}}`「信号规则」表为准。

| 编号 | 监测对象 | 等级 | 绿灯 | 黄灯 | 预警红线 | 硬红线 | 升级条件 |
|---|---|---|---|---|---|---|---|
| K01 | 外交关系级别变动 | 一级 | 无变更 | 领导人表态 | 召回大使 / 降级 | 断交 | 官方原文即升级复核 |
| K02 | 制裁 / 出口管制 | 一级 | 无新增 | 名单扩充讨论 | 新增单边制裁 | 全面制裁 / 二级制裁 | 逐条核对法律文本 |
| K03 | 条约签署 / 退出 | 一级 | 无 | 谈判启动 | 签署待批准 | 批准生效或正式退出 | 并列条约文本条款 |

| K07 | 冲突 / 停火 | 一级 | 无升级 | 局部摩擦 | 全面冲突 | 停火破裂 | 并列多方口径，不采信单方 |
| K08 | 国际司法 / 仲裁裁决 | 三级 | 无 | 程序启动 | 临时措施 | 实体裁决 | 并列当事方回应 |

## 七、重大事件触发器

**事件触发（主节拍）**：

```
- 各国外交部声明 / 发言人表态 → 外交关系专题
- 制裁、出口管制、投资限制新规 → 制裁合规专题
- 条约签署 / 批准 / 退出 → 条约专题
- 国际组织峰会、决议、席位变动 → 多边机制专题
- 冲突升级 / 停火谈判 → 冲突专题（并列多方口径）
```

**年度**：

```
- UN Treaty Collection 年度更新 → 条约状态基线
- 各国外交政策白皮书 / 战略文件 → 政策基线
- 国际组织年度报告 → 机制运行基线
- 台账年度复核 → 口径冲突与已修正事实清单更新
```

## 八、先行信号标准矩阵

① 官方声明与公报；② 条约与决议文本；③ 制裁与合规清单；④ 组织席位与投票记录；⑤ 使领馆与人员往来；⑥ 冲突与停火动态。

**失真信号清单**：匿名消息、单一媒体爆料、把表态当政策、把签署当生效、把智库报告当官方立场。

## 九、专题预警配置

**制裁与合规专题**（默认注册专题）：出现新增制裁、出口管制或投资限制时触发。

- 工具识别：逐条给出法律依据、适用对象、生效日与例外条款。
- 影响矩阵：按主体类型 / 行业 / 地域三维展开。
- 反向证据：并列豁免、许可与既有合规安排。
- 结论边界：不构成法律意见，建议咨询执业法律专业人士。

- **分层交付**：决策摘要（≤1 屏，仅结论）/ 证据层 / 原始层；共享 boilerplate 上移通用基座第十节（规范：`engine/templates/information-layering-spec.md`）。

- **指针引用**：正文用「指标编号 + 指针」（K01–K08、RL-01–RL-05、G01–G05）。
- **决策卡与行动协议**：见 `engine/templates/decision-delivery-spec.md` 第一 / 三节。
- **阈值校准**：首次中期回测 2027-06；校准前标注口径见 `engine/templates/decision-delivery-spec.md` 第六节。
- **场景切片**：主场景 **政策制定**；次场景 **合规应对**。
- **版本治理**：核验 / 收敛型运行不升级版本号，标注「本期读数时点」。
- **盲区**：优先补齐非英语官方原文与条约保留条款。
