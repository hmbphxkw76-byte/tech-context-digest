## 五、四维必查内容

### 5.1 价格与成交
必须交叉核验的英文机构季度报告：Savills、CBRE、JLL、C&W Core、Cavendish Maxwell、ValuStrat、Knight Frank、PropertyIndex / DXBinteract、Property Monitor（如有）。

必须区分并列表（口径说明）：

| 口径 | 说明 |
|---|---|
| 表观均价 | 受成交结构影响，不能直接当资产贬值 |
| 同质化价格变动 | 更接近同一资产价值变化 |
| 混合调整指数 | PIX 等，按固定日期发布版 |
| 成交中位价 | 原始登记中位，非混合调整 |
| 挂牌要价 | 卖方预期，非成交价 |
| 顶级/豪宅均价 | 篮子各机构不同，不可直接比较 |

必须列明：期房/现房成交结构、二手/转售占比、豪宅成交结构变化、顶级价格方向冲突、成交金额与笔数的差额（单笔金额）、成交结构对表观均价的影响（结构效应）。

DLD 官方锚：
- 成交登记：`https://www.dubaipulse.gov.ae/data/dld-transactions/dld_transactions-open`
- 官方价格指数：`https://dubailand.gov.ae/en/open-data/indexes-home/`

要求：用 DLD 登记做方向校验；能下载则重算，不能下载则明确写"未重算"。表观均价与同质化价格的差额，必须解释为成交结构效应，不得解释为同一资产贬值。豪宅必须注明门槛；不同门槛不可直接比较（如 Savills `>AED10m` 与 Knight Frank `>US$10m`）。

### 5.2 供需与管道
必须列明：当季实际交付套数、公寓占交付/待交付比例、新推盘套数、交付兑现率、次年计划交付、中期管道总量、计划量修订（同一机构前后版本）、住宅存量、人口与家庭户数。

必须区分：实际交付、计划交付、已公告/登记管道、新推盘（销售前置）、建筑许可（开工前置）、竣工证书（与交付套数不是同一单位）。

官方来源：
- Dubai Municipality / Media Office 建筑许可、许可面积、竣工证书
- Digital Dubai / DDSE 人口
- Dubai Statistics Centre
- DLD units 数据集：`https://www.dubaipulse.gov.ae/data/dld-registration/dld_units-open`

要求：计划量必须按兑现率折算成实际区间，不得当作交付事实。次年计划量若机构分歧 >20%，必须分轨呈现，不得取中值或合并。公寓占比使用最新计划口径，但必须标注"计划值"。许可建筑面积同比 >+30% 时，必须触发中期供给复核。交付兑现率 <45% 时，必须重算次年实际交付区间。

### 5.3 租赁与收益
必须列明：Ejari 租约登记量、新签/续约合约数、新签租金中位、续约租金中位、降租续约占比（最敏感先行指标）、持平/涨租续约占比、同质化新签与续约价差、分区毛收益率、分区净收益率、毛净差、挂牌租金与登记租金背离、挂牌量/单盘询盘、DLD Smart Rental Index 规则变化。

官方来源：
- Ejari 租约登记：`https://www.dubaipulse.gov.ae/data/dld-registration/dld_rent_contracts-open`
- DLD 租金指数：`https://dubailand.gov.ae/en/eservices/rental-index/rental-index/`
- DLD FAQ：`http://dubailand.gov.ae/en/frequently-asked-questions`

要求：降租续约占比 >20% 即红灯（RL-02 阈值见[业务配置第六节](./business-config.md)）；挂牌租金与登记租金背离 >10pp，说明挂牌端未出清。毛收益率必须注明是毛口径还是净口径；毛净差 >1.5pp 需提示持有成本侵蚀。不同收益率口径并列，不取均值。新签与续约价差必须区分"新租客折价"与"全市租金下跌"；不得把同质化 0.0% 外推为"租金整体坚挺"。

### 5.4 宏观先行（全部官方英文一手）
必须列明：CBUAE 基准利率、3M/6M/1Y EIBOR、AED/USD 参考汇率、Fed 目标区间/票型/SEP/会议日历、CBUAE 季度经济评论与信贷景气调查、银行信贷/存款/M1/M2/M3、UNCTAD WIR FDI、IMF UAE 国家页、U.S. EIA STEO Brent、Dubai DET 游客与酒店入住率、DDSE 劳动力调查结果（若已发布）、GDP/CPI。

要求：EIBOR 只用官方定盘，不用单日盘中报价。利率红线的确认标准是"月均连续 2 期同向"，不是单日破线。Fed 票型与点阵图必须双确认（声明 + 纪要）。GDP/CPI 预测分歧 >2pp 或方向相反，必须用区间，不得取点值。迪拜酋长国 CPI 与 UAE 联邦年度预测不得混算。就业/失业率若无官方数据，标灰灯；禁止引用商业网站无依据数据。

## 六、分析方法（类型模板方法论的本项目实例）

先行信号矩阵、结构红线归一化、传导链、已定价/未定价/反向声音、条件化决策框架、升级复核、供给情景重算的方法框架见[季度类型模板第二节](../../../../../engine/templates/market-monitoring/prompt-quarterly-analysis-template.md)。本项目实例化：

### 6.1 先行信号矩阵
- 按 `{{REGISTRY_PATH}}` 内「信号规则」K01–K15 逐条判定；标准矩阵 8 项与失真信号清单见[业务配置第八节](./business-config.md)。
- 必须以首期基线「4 红 3 绿 1 灰」为对比锚，按最新数据重算，不得机械沿用。
- 每个信号必须写：本期读数、方向、信号灯、连续 2 期确认进度、失真剔除说明、对公寓市场的含义。

### 6.2 结构红线（RL-01–RL-09）
- 红线登记簿阈值见[业务配置第六节](./business-config.md)（运行前从 `{{REGISTRY_PATH}}`「信号规则」表读取）；归一化方法与状态分级见季度类型模板。
- 普通红灯允许"触发但待确认"；结构红线一旦触发：启动升级复核、重算情景、暂停新增杠杆类决策建议、不提供买卖价位或仓位建议。
- 报告必须同时写：普通红灯数量（矩阵口径 + K 规则口径）、结构红线触发数 / 临界数、红线阈值为本机制自设（非官方）、"红灯 ≠ 红线"的解释。

### 6.3 传导链（本项目五条）
1. **利率**：Fed / CBUAE / EIBOR → 浮动按揭重定价 → 月供 → 可负担房价 → 成交量 → 价格。领先 2–4 季。
2. **供给**：许可 / 新推盘 → 开工 → 2–4 年交付 → 存量 → 空置 → 租金/价格。领先 8–16 季。
3. **交付→租赁**：交付 → 空置竞争 → 房东议价权 → 降租续约 → 登记租金 → 收益率。领先 0–2 季。
4. **人口/FDI/就业**：FDI / 人口 → 企业设立 → 外籍就业 → 家庭形成 → 租赁需求。领先 2–6 季。
5. **旅游/短租**：游客 / 入住率 → 短租收益 → 投资性需求 → 公寓价格。领先 3–9 月。

每条链必须写：当前读数/证据、领先期、已定价程度、尚未定价因素。

### 6.4 反向声音（建议三条）
更空——供给洪峰被低兑现率掩盖；更多——软着陆、量跌价稳；统计幻觉——表观均价/中位租金被结构放大。反向声音必须标明证据与不确定性，不得为了平衡而编造。

### 6.5 条件化决策框架（覆盖条件组）
① 融资再紧；② 租金确认下行；③ 供给兑现回升；④ 需求分母仍强；⑤ 红线触发；⑥ 油价再上修。

### 6.6 升级复核（本项目触发条件）
季度内出现任一红灯；口径分歧 >20%；交付兑现率 <45%；许可面积同比 >+30%。

### 6.7 供给情景重算
方法：`计划量 × 兑现率 = 实际交付区间`。兑现率至少三档（运行前从 `{{REGISTRY_PATH}}` 读取最近已核验值填入；不得在模板内硬编码）：
- 档位 1：最近半年度实际兑现率
- 档位 2：上一财年全年实际兑现率
- 档位 3：Knight Frank 2022–24 约值（二手引述，需核实原文）

要求：公寓口径再乘公寓占比（计划值，取自台账）；CM 与 C&W 分轨，不合并、不取中值；各年分别列示；每个结果标注"区间/情景"，不是交付事实；存量增速与人口增速对比时，必须注明跨期、仅量级参考。

## 八、报告结构（12 节，类型模板骨架的本项目实例）

11. **页脚**：报告路径、指标台账路径、本期新增/补入内容。
