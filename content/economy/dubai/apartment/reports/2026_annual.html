3.3 假设重设（三项）

  1. 计划锚由单点改为区间：2027 计划交付锚由 CM H1 版单点 162,500 套改为跨机构区间 60,000 / 146,400 / 162,500 套（低 / 中 / 高），情景一律用区间，不得用单点。假设
  2. 兑现率由单档改为三档：由「最近半期 41.3%」单档改为 41.3% / 48.9% / 60%（近半期 / 上一完整年度 / 历史区间 KF 2022–24 约 60%）三档。假设
  3. 2029–2030 供给由外推改为管道残差：长期管道 >525,000 套（2027–2030）扣除 2027 / 2028 中值后的残差按剩余年份均分推导，并标注「误差最大」。假设

三项假设核验进度 0/3：均未取得官方或可下载一手序列确认；首次核验窗口 2027-06 中期回测。

4.5 传导链复盘

周期定位：本报告将 2026 年定位为「金融条件收紧主导的方向性下行初期」——方向层（K02 / K04 / K06 硬红·方向）已成立，水平层（价格与成交量的绝对水平）未确认；被复盘年份全年值待 2027-01 发布后复核。

传导量化（弹性与时滞）：政策利率 → EIBOR 的弹性近似 1:1（CBUAE 年内跟随式加息 150bp，3M EIBOR 月均上行 52bp）；EIBOR → 月供的时滞取决于重定价周期与 margin（本轮自算未计 margin，故为「瞬时全额传导」下限估计）；EIBOR → 成交量的弹性本轮无法估计（就业 / 收入盲区 B02 / B15 未消号），仅能给出方向。

主导传导链（政策利率 → EIBOR → 月供 → 可负担性 → 成交量 / 价）：Fed 暂停降息但保留加息选项 → CBUAE 全年 +150bp → 3M EIBOR 上行 52bp（月均）→ 等额本息月供上升（假设乘积：贷款 AED 2,000,000 / 25 年，月供由 10,447 升至 10,992，随利率情景呈区间）→ 成交量 −38% 与同质价格 −4% 量级下行。该链条在「量」上已确认，在「价」的水平上未确认。
