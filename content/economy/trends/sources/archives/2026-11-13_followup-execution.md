## 附录 A：关键口径对齐说明（相关方统一理解）

| 术语 | 定义 |
|---|---|
| 数据截止日（DATA_CUTOFF） | 报告命名与标题锚定此日期，**非执行日**；文件名 `{YYYY-MM-DD}_weekly.html` |
| 结构锚 | 首期周报的八节结构与结论；后续每期逐字对齐（本业务线以首期周报为锚，不出九节基线文档） |
| 核验轻运行 | 无触发且无实质变化时的降级运行；「没有数据」写成可核验陈述，禁止虚构变化 |
| T+1 刷新 | 与上期数据截止日仅隔 1 日时，报告头部标注 |
| 已修正事实清单 | 台账防回退机制；每期运行前完整继承，与清单冲突的旧结论不得复活 |
| 单一事实源 | `prompts/business-config.md`；变量 / 主题矩阵 / 来源分级 / 触发器以其为准 |
| 八节骨架 | s1 要点 Top5 / s2–s4 三板块 / s5 数据看板 / s6 风险与不确定性 / s7 可执行启示 / s8 参考来源 |
| 12 期归档 | weekly 保留 12 期，超限自动移入 `reports/archives/` |
| 来源分级 | ① 官方一手（唯一可直接采信）② 行业机构 ③ 挂牌门户 / 数据库 ④ 媒体转述（只作线索） |
| 结论边界 | 可执行启示只给「条件 → 判读 → 框架性含义 → 风险提示」；不给汇率点位、买卖价位与仓位建议 |
