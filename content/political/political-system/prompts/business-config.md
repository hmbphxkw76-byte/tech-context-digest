## 二、受众定位

- **受众**：比较政治研究者、公共政策分析者、涉外事务团队。
- **视角**：以官方法律文本、选举公告与治理统计为主线，做制度—机制—影响解读。
- **结论边界**：只给框架性说明与可核验信息，**不构成政治立场、法律或选举建议**；不预测选举结果。

---

## 三、术语口径区分（表格与正文中不得混用）

- **选举制度 ≠ 政党制度**：多数制 / 比例代表制 / 混合制与一党 / 多党 / 两党分列。
- **投票率 ≠ 得票率**：登记选民口径与实际投票口径分列。
- **中央政府 ≠ 地方政府**：事权与财权划分须注明层级。
- **廉政指数 ≠ 腐败案件数**：感知类指数与司法案件统计口径不同。
- **公民社会 ≠ 非政府组织**：结社、集会、媒体自由度分列。
- **宪政体制 ≠ 实际运行**：文本规定与实际运作并列，不互相替代。

## 四、来源优先级（通用基座第四节的实例化，冲突时报双份并标注）

① **官方一手**：各国议会 / 政府 / 选举委员会 / 宪法法院官方文本、各国统计局、Transparency International 官方方法文件、OECD 治理指标
＞ ② **行业机构**：V-Dem Institute、International IDEA、各国官方认证选举观察机构
＞ ③ **挂牌门户 / 数据库**：V-Dem Dataset、OECD Government at a Glance、World Bank WGI、各国法律数据库
＞ ④ **媒体转述**：Reuters、Bloomberg、各国主流媒体（须标「需核实原文」）

> **Freedom House / 商业评级机构**仅作线索，须回官方或方法文件核验后使用。

**机构获取优先级 P0–P5**：

| 层级 | 渠道 | 使用规则 |
|---|---|---|
| P0 | 官方法律 / 选举公告 / 议会记录 | 唯一可直接采信层，标「已核验」 |
| P1 | 官方 PDF / 统计年鉴 | 记录版本、发布日期、页码 |
| P2 | 国际治理数据库 | 用于跨国对照快照，须注提取日期与版本 |
| P3 | 英文媒体 | 只用于发现线索；数值标「需核实原文」 |
| P4 | 智库与行业机构 | 交叉验证方向；不替代 P0 |
| P5 | 官方法律数据库 / 宪法文本 | 最终裁决制度与程序口径 |

**最小可替代集**：官方法律文本 + V-Dem Dataset + 该国统计局；结论置信度降为「方向高、幅度中、时点低」。

## 七、重大事件触发器

**事件触发（主节拍）**：

```
- 选举公告 / 结果 / 争议 → 选举专题
- 修宪 / 司法改革 → 制度专题
- 政府组建 / 不信任案 / 解散 → 政局专题
- 重大腐败判决 / 廉政指数发布 → 廉政专题
- 集会与结社规制变更 → 公民社会专题
```

**年度**：

```
- V-Dem Dataset 年度更新 → 跨国治理基线
- OECD Government at a Glance 发布 → 治理结构基线
- 各国选举日历 → 政治周期基线
- 台账年度复核 → 口径冲突与已修正事实清单更新
```

## 八、先行信号标准矩阵

① 法律与修宪文本；② 选举公告与结果；③ 议席与组阁动态；④ 廉政指数与案件；⑤ 公民社会规制；⑥ 数字治理制度。

**失真信号清单**：民调单期波动、匿名爆料、把表态当立法、把指数当案件、把文本规定当实际运行。

---

## 九、专题预警配置

**选举与政局专题**（默认注册专题）：出现选举延期 / 取消、政府解散、不信任案通过时触发。

- 事实核对：官方公告 + 法律依据 + 时间表，逐条附 URL。
- 影响矩阵：按制度稳定性、政策连续性、合规风险三维展开。
- 反向证据：并列既有制度弹性、历史先例与各方反应。
- 结论边界：不预测选举结果，不构成政治立场。

## 十三、信息分层与决策交付（强制项）

- **分层交付**：决策摘要（≤1 屏，仅结论）/ 证据层 / 原始层；共享 boilerplate 上移通用基座第十节（规范：`engine/templates/information-layering-spec.md`）。

- **指针引用**：正文用「指标编号 + 指针」（K01–K08、RL-01–RL-05、G01–G05）。
- **决策卡与行动协议**：见 `engine/templates/decision-delivery-spec.md` 第一 / 三节。
- **阈值校准**：首次中期回测 2027-06；校准前标注口径见 `engine/templates/decision-delivery-spec.md` 第六节。
- **场景切片**：主场景 **政策制定**；次场景 **合规应对**。
- **版本治理**：核验 / 收敛型运行不升级版本号，标注「本期读数时点」。
- **盲区**：优先补齐非英语官方法律文本与实际执行口径。
