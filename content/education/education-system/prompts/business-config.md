## 二、受众定位

- **受众**：教育政策研究者、国际比较教育研究者、教育机构与政府事务团队。
- **视角**：以官方制度文本与可核验统计为主线，做跨国 / 跨制度对照与政策影响解读。
- **结论边界**：只给框架性说明与可核验信息，**不构成升学、留学、资格认证、法律个案意见**；排名与认证须用官方口径，不引用商业排名作为结论。

## 三、术语口径区分（表格与正文中不得混用）

- **学历 ≠ 学位**：学历（education level attained）与学位（degree awarded）分列，不得互相替代。
- **毛入学率 ≠ 净入学率**：高等教育毛入学率（GER，含超龄 / 低龄人口）与净入学率（NER）口径不同，禁止合并或互相折算。
- **义务教育年限**：区分「学年口径」（如 9 年）与「年龄口径」（如 6–15 岁），须注明来源国定义。
- **学历互认 ≠ 学位互认**：协议名称与覆盖层级须逐条核对原文。
- **认证 ≠ 质量**：官方认证状态不等同于教育质量评价。
- **ISCED 等级**：跨国对照统一标注 ISCED 2011 等级，版本变更时并列新旧对照。

## 四、来源优先级（通用基座第四节的实例化，冲突时报双份并标注）

① **官方一手**：UNESCO UIS、OECD（Education at a Glance / Data）、各国教育部与主管机关（中国教育部、日本 MEXT、韩国教育部、英国 DfE / OfS、美国 ED / NCES、德国 KMK）、EU Eurydice、ISCED 分类文件
＞ ② **行业机构**：IEA（PISA / TIMSS / PIRLS）测评报告、OECD 教育研究与创新中心（CERI）
＞ ③ **挂牌门户 / 数据库**：UIS.stat、OECD Data、World Bank EdStats、e-Stat、Eurostat
＞ ④ **媒体转述**：Reuters、Bloomberg、各国教育专业媒体（须标「需核实原文」，不得与官方一手同等处理）

> **商业排名（QS / THE / ARWU 等）不列入采信层级**，仅可作线索，且必须回官方页核验后再使用。

**机构获取优先级 P0–P5**：

| 层级 | 渠道 | 使用规则 |
|---|---|---|
| P0 | 官方公报 / 法规数据库 / 教育部原文 | 唯一可直接采信层，标「已核验」 |
| P1 | 官方 PDF / 统计年鉴 / 测评报告 | 记录发布日期、版本、页码 |
| P2 | 国际组织统计门户 | 用于跨国对照快照，须注提取日期 |
| P3 | 英文媒体与专业媒体 | 只用于发现线索；数值标「需核实原文」 |
| P4 | 其他行业机构 | 交叉验证方向；不替代 P0 |
| P5 | 官方条文 / 认证机构名录 | 最终裁决学历互认、认证状态口径 |

**最小可替代集**（官方原文暂缺时）：UIS.stat + OECD Data + 该国教育部新闻稿；结论置信度降为「方向高、幅度中、时点低」。

## 七、重大事件触发器

**事件触发（主节拍）**：

```
- 各国教育部 / 主管机关政策发布与征求意见 → 对应专题解读
- 立法机关教育相关修法 → 学制与互认专题
- UNESCO / OECD 教育统计与测评报告发布 → 年度台账与跨国对照
- 学历互认协议签署 / 生效 / 退出 → 互认专题
- 认证机构名单或资质变更 → 认证专题
```

**年度**：

```
- UNESCO UIS 年度统计更新 → 跨国基线
- OECD Education at a Glance 发布 → 支出与结构基线
- IEA 测评结果发布 → 仅作线索，不单独下结论
- 台账年度复核 → 口径冲突与已修正事实清单更新
```

## 八、先行信号标准矩阵

① 政策文本（修法 / 规制 / 指南）；② 立法与预算信号（教育支出占比）；③ 统计门户快照（GER / NER / 师生比）；④ 互认与认证状态；⑤ 国际测评结果；⑥ 国际学生流动。

基线首期矩阵计数为对比锚；重算不得机械沿用。

**失真信号清单**：商业排名波动、单个学校公告、把单一年份测评波动当趋势、把「认证」当「质量」、把征求意见当正式制度。

## 九、专题预警配置

**互认与认证专题**（默认注册专题）：当出现学历 / 学位互认协议签署、生效、退出，或认证机构资质撤销时触发。

- 原文条款定位：逐条给出条款、生效日、适用对象、过渡期。
- 影响对象矩阵：按国别 / 学历层级 / 认证机构三维展开。
- 反向证据：并列该国学制差异、既有的双边协议与例外条款。
- 结论边界：不构成认证个案意见，建议读者查官方认证渠道。

- **分层交付**：决策摘要（≤1 屏，仅结论）/ 证据层（逻辑）/ 原始层（台账与来源）；共享 boilerplate 上移通用基座第十节，不复制（规范：`engine/templates/information-layering-spec.md`）。
