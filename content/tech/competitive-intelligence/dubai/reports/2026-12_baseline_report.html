一句话定位：迪拜 AI 网安竞争格局由三股力量叠加而成——政策与合规（DESC / ISR / 国家网络安全战略）构成准入门槛，主权 AI 基建与资本（G42 系、Stargate UAE、微软–G42）构成纵向整合轴，全球厂商区域总部与本地 MSSP（e& / Help AG、CPX、Cloud4C）构成交付层；模型层高度集中（Anthropic / OpenAI 合计占全球企业 LLM API 支出 86%）通过 API 与产品能力向本地传导。

④ 输出层基线报告（对比锚）；月度报告（主更新）；事件触发专项件；登记册回写与变更摘要。

2.2 监测节拍：月度主更新 + 事件触发升级

  • 月度主更新：动态矩阵全量刷新 + 档案卡增量修订，输出九节更新版报告；无触发则降级为核验 / 收敛型轻运行，登记册标注「截至本次运行日期无更新」，不得虚构变化。
  • 事件触发升级：命中业务配置 R1–R6 信号规则（定价重构 / 并购 / 换帅 / 新产品线 / 合规资质 / 资本动作）即当期核实并升级，不等待月度窗口。
  • 对比锚：本基线报告为后续所有周期的对比锚；分层口径、档案卡结构与裁决规则被后续更新完整继承。

3.3 周期定位与格局演变方向

周期定位：当前处于「政策强监管 + 主权基建放量 + 模型层集中」的周期阶段——ISR v3.1 / NCAP / AI 安全政策构成合规门槛，Stargate UAE（5GW AI 园区 / 1GW 算力集群，首批 200MW 计划 2026 上线）与 G42 系垂直整合构成供给端主轴，模型层 86% 双寡头结构构成能力端约束。[Source: OpenAI, 2025]

格局演变方向（推断）：① 合规门槛抬升将挤出无资质的小型 MSSP，集中度上行；② 主权玩家（G42 系、Moro Hub）与全球厂商区域总部的边界趋于模糊，合资 / 生态绑定增多；③ 模型层集中通过 API 与分级开放（如 Mythos 5.2 仅向验证机构开放）向本地产品嵌入传导，本地化合规与数据主权成为差异化变量。以上均为推断，非事实。

七、风险与盲区

7.1 情报盲区

  • 渠道覆盖缺口：自由区（DIFC / ADGM / DIC / JLT）内部公告与招标未全覆盖；部分玩家仅中文 / 聚合源可及，英文权威页缺失。
  • 时滞：官方发布滞后于动作发生（资质、任命、合同）；媒体转述再滞后一层；本基线以 2026-11-13 为限，之后动作不在本期范围。
  • 无法观测的私有动作：非公开合同、定价谈判、未公告的并购意向不在公开来源内，档案卡相应字段只能标「待核实」。
  • 模型层—交付层传导时滞：模型版本发布到本地产品嵌入存在时滞，矩阵中的模型动作不等于本地交付动作，二者须分开登记。

7.2 玩家弹性差异（判断）

垂直整合型玩家（G42 系）对供应链与政策冲击的弹性较高——算力、云、安全、应用内部协同可对冲单一环节中断；单一渠道 / 单一区域代理商弹性较低，政策或渠道变动即放大风险。主权资本型玩家（Moro Hub、Hub71）对政策方向弹性高，但对商业化速度弹性低（判断）。

7.3 反向声音（对自身判断的复核）

反向声音一：集中度结论对口径高度敏感

Mordor 与 Global Market Insights 对阿联酋网安市场规模给出 8.2 亿 vs 34 亿美元（相差约 4 倍）；Menlo 的 86% 双寡头份额为全球口径。任何「迪拜 AI 网安集中度」单一数字都可能误导，须始终并列口径。（判断）

反向声音二：AI 自动化可能压缩入门级需求

Gartner 预计 2028 年 AI 将自动化部分 L1 SOC 工作；竞争焦点向价值链上移，而非总量线性扩张。若如此，以「人员缺口」推导的需求增量需打折。（判断 / 推断）[Source: ISC2, 2025]

反向声音三：开源份额高 ≠ 商业影响大

开源模型占 token 19% 但仅占支出 4%；以 token 份额推断竞争格局会高估开源厂商的商业影响。（判断）[Source: Menlo Ventures, 2026-11]
