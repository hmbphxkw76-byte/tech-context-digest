# 迪拜 AI 应用行业 · 月度刷新提示词（行业深度研究型 · 更新节拍）

> **用途**：月度刷新《迪拜 AI 应用行业调研》基线结构，注入最新市场、政策、云与主权平台、生态变化，保留全部已核实事实与来源锚点。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：中文九节调研报告（canonical 富样式自包含 HTML），落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}_monthly.html`）。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../../../../../engine/templates/prompt-generic-base.md) × [监测报告通用规范](../../../../../../engine/templates/monitoring-common-spec.md) × [行业深度研究型刷新模板](../../../../../../engine/templates/industry-research/prompt-annual-refresh-template.md) × [业务专属配置](./business-config.md)。质量规则见通用基座与通用规范；行业研究型骨架见类型模板；冲突时以本文件为准。

## 一、任务目标

读取基线报告，结合截至 `{{CURRENT_DATE}}` 的最新英文来源，完成迪拜 AI 应用行业全景的**月度刷新**：更新市场数据、政策与战略动态、主权平台与云厂商 AI 服务、本地 AI 应用开发与代理、创业池与政府/企业采购信号；保留基线全部已修正事实、来源锚点与结构骨架，不新增未经核实的结论。

## 二、刷新范围（九节逐节处理）

| 节 | 刷新动作 |
|---|---|
| 一、执行摘要 | 更新结论与关键数字，标注本期新增 / 修正 / 无变化 |
| 二、研究范围与方法 | 更新行业边界与口径裁决（多口径不合并） |
| 三、产业链图谱 | 更新上游模型/算力、中游平台与产品、下游交付与采用的分层与代表方 |
| 四、市场规模与格局 | 更新 UAE / 全球多口径规模、增速与结构（回原始页校验） |
| 五、头部玩家与竞争格局 | 更新 G42/Core42、Moro Hub、云厂商、Hub71 与本地开发/代理动态 |
| 六、驱动因素与风险 | 更新政策、主权 AI 基建、采购与人才信号 |
| 七、趋势判断 | 更新推断与反向证据，标注「推断」 |
| 八、数据治理 | 更新来源时效、冲突登记与局限 |
| 九、来源清单 | 追加本期新来源，保留历史来源 |

## 三、硬性约束

1. **仅英文来源**；关键数字回原始页校验，禁止用中文来源或模型记忆补齐。
2. **结构逐字继承基线**，九节标题与顺序不变；不新增节、不删节。
3. **已修正事实清单**（见 business-config 第七节）全部保留，不得回退；如本期有新修正，追加并附来源。
4. **事实与推断分离**：数据变化标来源；判断标「推断」，不承诺确定结论。
5. **信息分层**：执行摘要只放已核验 + 部分核验；不确定项标「未核实」并列入局限。
6. **口径纪律**：UAE AI 全口径（IMARC）≠ 全球企业 AI（Grand View）≠ 全球 AI（TBRC）；本地与全球分列，禁止相加或混算。

## 四、执行方式

1. 启动 3–5 个并行研究子代理（市场规模 / 政策与主权平台 / 云与产品生态 / 创业与采购），全部限定英文源、逐点引用。
2. 主代理读取基线报告，逐节比对，保留可复用段落，更新变化段落。
3. 冲突数据并列登记，不静默择一；无法核实项列入第八节局限。

## 五、输出格式

- canonical 富样式自包含 HTML，落盘 `{{OUTPUT_PATH}}`；md 源稿存 `sources/` 同名存档。
- 文末标注数据来源、口径与「推断」边界。

## 六、质量自检

- [ ] 九节结构与基线逐字一致
- [ ] 全篇零中文来源，关键数字可回溯原始页
- [ ] 已修正事实清单无回退
- [ ] 事实与推断分离，执行摘要仅含已核验 / 部分核验
- [ ] 本期新增 / 修正 / 无变化已标注
- [ ] 多口径规模并列不合并

## 七、Agent 执行约定

- 不得修改用户上传的只读附件；不得编造缺失数据。
- 同源已核实资产见 business-config 第四节 ⑤，冲突时并列登记。
