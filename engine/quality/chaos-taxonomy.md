# 信息混乱场景分类判定表（chaos-taxonomy）

> **用途**：阶段 3（语义判定）与阶段 4（定级）的统一分类口径。每个场景给出**可观测判定特征**、**检测层**、**严重级**、**触发指标**、**自动修复动作**与**修复后验证**。
>
> **纪律**：判定特征必须可观测、可复述；不得出现「感觉不一致」这类不可判定描述。修复动作必须映射到 [repair-sop.md](./repair-sop.md) 的具体条款。

## 二、场景详细说明

### C01 主题间内容冲突（P0）

- **判定特征**：
  - 同一指标在两条业务线报告中数值不同，且均未标注口径差异；
  - 同一事件在不同报告中结论方向相反；
  - 同一来源被不同报告引用为不同数值。
- **检测层**：混合。工具初筛（登记册数值比对）+ Agent 复核（跨报告语义比对）。
- **触发指标**：A-03 数值一致率 < 99%；L-01 跨章节数值一致率 < 99%。
- **修复动作**：按权威源优先级裁决（见 README 第四节）；低权威源对齐或标「需核实原文」；无法裁决则并列呈现并列入待复核清单。
- **修复后验证**：复比对冲突数 = 0，或全部剩余项已显式并列标注。

### C02 信息重复冗余（P1）

- **判定特征**：归一化后相似度 ≥ 0.9 的段落，且后出现的段落无新增事实 / 数据 / 结论。
- **检测层**：LLM。
- **触发指标**：R-03 跨主题重复率 > 5%。
- **修复动作**：保留权威源（更高来源层级 / 更早基线 / 更完整版本），其余改为引用或删除；同类段落合并为单一权威段落。
- **修复后验证**：重复率 ≤ 5%，且被删段落无独有信息（逐段确认）。

### C03 逻辑断层（P1）

- **判定特征**：结论段缺前提；「结论先行」中的结论在后文无对应证据；章节间无过渡导致推理跳跃。
- **检测层**：LLM。
- **触发指标**：L-04 结论-证据一致率 < 95%。
- **修复动作**：补桥接段落或补证据；无法补则将该结论降级为「待核实」，并移入「待复核清单」。
- **修复后验证**：结论-证据一致率 ≥ 95%。

### C04 内容归属错误（P0）

- **判定特征**：
  - 报告文件位于业务目录之外（仓库根、`engine/templates/` 等）；
  - 报告内容主题词命中另一业务线，且与所在目录主题不符。
- **检测层**：工具（`classify_reports.py`）+ LLM（内容主题判定）。
- **触发指标**：R-01 归属正确率 < 100%；R-05 主题-内容匹配率 < 95%。
- **修复动作**：工具判定项执行 `classify_reports.py --apply`；LLM 判定项先备份，再移动并更新索引 / 导航引用。
- **修复后验证**：归属正确率 100%；`check_links.py` 无新增断链；索引 / 汇总页重新生成。

### C05 信息缺失（P0 / P1）

- **判定特征**：必填字段为空；必填节缺失；关键数字无来源；登记册指标未被任何报告覆盖。
- **检测层**：混合。
- **触发指标**：C-02 / C-03 / C-04 / C-05 / A-01 任一越界。
- **修复动作**：能补则补（补采 / 补写 / 补来源）；不能补则标「未核验」或「暂无数据」，并写入「待复核清单」。**严禁编造**。
- **修复后验证**：必填字段完整率 100%；无法补项全部在待复核清单中。

### C06 表述矛盾（P0）

- **判定特征**：同一报告内前后表述冲突（如「上升」与「下降」并存且指同一对象）；数值口径前后不一。
- **检测层**：LLM。
- **触发指标**：L-01 / L-05 越界。
- **修复动作**：复核原始来源，修正错误表述；将修正记入「已修正事实清单」（格式见通用基座第五节）；不得回退基线修正记录。
- **修复后验证**：复比对矛盾数 = 0；已修正事实清单已续写。

### C07 来源缺失 / 断头数字（P0）

- **判定特征**：正文出现数值但无来源注；来源不可达；媒体转述未标「需核实原文」。
- **检测层**：混合（`check_links.py` + LLM）。
- **触发指标**：A-01 < 95%；A-02 < 100%；A-05 < 100%。
- **修复动作**：补来源；无法补则标「需核实原文」或删除该数值；链接失效则修正或替换为可达来源。
- **修复后验证**：来源可追溯率 ≥ 95%；链接可达率 100%。

### C08 口径混用（P1）

- **判定特征**：同一指标多口径（如均价 / 中位价）静默择一或混用，未并列呈现。
- **检测层**：LLM。
- **触发指标**：L-02 < 100%；A-02 越界。
- **修复动作**：按 business-config「术语口径区分」统一表述；多口径并列呈现，不得取均值。
- **修复后验证**：口径一致率 100%；并列清单与 business-config 一致。

### C09 断链 / 断头锚点（P0）

- **判定特征**：`href="#x"` 无对应 `id`；仓库相对路径 / `./` / `../` 链接目标不存在；GitHub `blob/main` URL 失效。
- **检测层**：工具。
- **触发指标**：A-05 < 100%；R-04 > 0%。
- **修复动作**：修正路径 / 锚点；批量迁移场景用专用路径改写脚本（或手工逐条）；无法修正则移除链接并保留文本。
- **修复后验证**：断链数 = 0；`check_links.py` 退出码 0。

### C10 阈值 / 红线不一致（P0）

- **判定特征**：K / RL 阈值在 business-config、`{{REGISTRY_PATH}}`、报告三处出现不同数值。
- **检测层**：混合。
- **触发指标**：L-03 < 100%；A-03 / C-04 越界。
- **修复动作**：以登记册「信号规则」表为唯一事实源，同步 business-config 与报告；记录版本变更。
- **修复后验证**：三处一致率 100%。

### C11 结构缺失（P0）

- **判定特征**：`h2.sec` 节数少于 `compliance-rules.json` 骨架；缺 `<title>`；周期报告缺顶部导航。
- **检测层**：工具。
- **触发指标**：C-01 < 100%；C-02 < 100%。
- **修复动作**：用 `compliance_check.py --scaffold <类型ID> [周期]` 取骨架，按模板补齐；不得增删节 / 调顺序。
- **修复后验证**：结构完整率 ≥ 100%；`compliance_check.py --check` 退出码 0。

### C12 术语不一致（P1）

- **判定特征**：同一术语多种写法；术语与词汇库 `terms.md` 词条 / 别名不符。
- **检测层**：混合（`vocab_tool.py check` + LLM）。
- **触发指标**：C-06 越界。
- **修复动作**：以词汇库为准统一；若词汇库缺失该词条，走 `import` 流程补入，不得手工改 `terms.md`。
- **修复后验证**：`vocab_tool.py check` 0 错误；全库术语写法一致。

### C13 时效过期（P1）

- **判定特征**：数据日期超出 business-config 声明的时效；来源过旧未标「滞后 N 期」。
- **检测层**：LLM。
- **触发指标**：A-04 < 90%；L-05 越界。
- **修复动作**：更新数据或显式标注「滞后 N 期」；不得外推 / 补值。
- **修复后验证**：新鲜度合规率 ≥ 90%。

### C14 格式漂移（P1）

- **判定特征**：出现漂移色；echarts 容器类名非 `.chart-eh`；缺 `.skip-link` / 焦点环 / `prefers-reduced-motion` / `@media print`；体积超预算。
- **检测层**：工具。
- **触发指标**：`page_build_check.py` / `lint_reports.py` 的 `[E]` / `[W]`。
- **修复动作**：`restyle_reports.py` 换 canonical 样式；`--rename-chart` 改名；补 a11y 强制项。
- **修复后验证**：`page_build_check.py` 0 `[E]`；`lint_reports.py` 无错误项。

### C15 维度倒置（P0）

- **判定特征**：目录路径中 `region` 段出现在 `sector` / `sub_direction` 之后。
- **检测层**：工具。
- **触发指标**：R-02 < 100%。
- **修复动作**：修正 `layout.json` 维度声明顺序 + 目录重构；批量改写引用（专用脚本或手工逐条）。
- **修复后验证**：`validate_layout.py` 退出码 0。
