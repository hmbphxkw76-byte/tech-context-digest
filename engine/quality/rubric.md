# 量化评估指标单一事实源（rubric）

> **用途**：本文件是内容质量评估的**唯一量化口径**。`prompts/02-evaluate.md` 逐项计算，`prompts/03-classify.md` 将越界项归入 15 类混乱场景。
>
> **纪律**：指标公式、阈值、检测层一经登记不得在提示词中另写一套；新增指标须先改本文件，再改提示词。
>
> **单一事实源（T3）**：下列指标的 `metric_id` / `threshold` / `severity` 以 [metrics-dictionary.json](../tools/metrics-dictionary.json) 为准；本文件与其冲突时以字典为准。

---

## 一、检测层定义

| 层 | 含义 | 执行者 | 可复现性 |
|---|---|---|---|
| `TOOL` | 由仓库脚本机械判定 | `engine/tools/` / `engine/vocabulary/script/` 脚本 | 完全可复现 |
| `LLM` | 语义判定 | Agent | 依赖上下文，须写下判定依据 |
| `MIXED` | 工具初筛 + Agent 复核 | 脚本 + Agent | 初筛可复现，复核有依据 |

---

## 二、严重级定义

| 级别 | 含义 | 门禁 | 处置 |
|---|---|---|---|
| `P0` | 阻断：必须修复才可交付 | 计入「未清 P0」，体系不通过 | 自动修复；无法修复则标「待人工复核」 |
| `P1` | 警告：应修复，可交付但须记录 | 不阻断 | 自动修复或标记 |
| `P2` | 提示：优化建议 | 不阻断 | 记录，择机处理 |

## 七、综合评分与门禁

- **维度健康度** = 该维度达标指标数 / 该维度指标总数 × 100%。
- **总体健康度** = 四个维度健康度的算术平均。
- **门禁**：

| 条件 | 结论 |
|---|---|
| P0 = 0 且 总体健康度 ≥ 90% | 通过 |
| P0 = 0 且 总体健康度 < 90% | 有条件通过（记录 P1，下轮优先） |
| P0 > 0 | 不通过（回到修复阶段） |

- **回归判定**：复验时「本轮新增问题数」必须为 0；若出现新增，视为修复引入，须回滚或修正。
