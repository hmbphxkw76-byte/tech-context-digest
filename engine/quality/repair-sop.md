# 标准化自动修复操作规范（repair-sop）

> **用途**：阶段 5 的执行口径。每个 SOP 条款对应 [chaos-taxonomy.md](./chaos-taxonomy.md) 的一个场景，给出**触发条件 → 标准化动作 → 执行命令 / 操作 → 修复后验证 → 回滚**。
>
> **总原则**：
> 1. **先备份后写盘**：任何修改前对被改文件建 `.bak`（或确认 git 工作区干净可回滚）。
> 2. **权威源优先**：冲突裁决以 README 第四节的优先级为准，低权威源对齐或标注。
> 3. **不删历史**：不删除历史报告 / 基线；只移动、合并、标注。
> 4. **幂等**：同一 SOP 重复执行不产生副作用。
> 5. **不可编造**：无法补全的信息标「未核验」/「暂无数据」，写入待复核清单。
> 6. **可追溯**：每次修复写入修复记录（见第六节格式），可回溯到 finding + SOP 条款。

---

## 零、修复分级

| 级别 | 处置 | 示例 |
|---|---|---|
| **自动执行** | 低风险、规则明确、可逆 | 格式漂移、断链修正、归属移动、结构补节、词汇同步、阈值同步 |
| **备份后执行 + 标记待复核** | 高风险、涉及内容增删改 | 跨主题冲突裁决、重复段落删除、结论修正、口径统一 |
| **仅标记不修改** | 需人工判断 | 权威源不明确的冲突、业务口径定义变更、阈值体系调整 |

> 自动修复**无需人工触发**；「备份后执行」同样自动完成，但产物带 `待人工复核` 标记，不阻塞流程。

## SOP-01 主题间内容冲突（C01）

- **触发**：C01 判定成立。
- **动作**：
  1. 定位冲突双方（主题 / 报告 / 章节）。
  2. 读取双方来源，按「官方一手 > 行业机构 > 挂牌门户 > 媒体转述」与「登记册 > 报告正文」裁决。
  3. 以高权威源为准修正低权威源；无法裁决则并列呈现并标「口径待核实」。
- **执行**：编辑低权威源文件；若涉及数值，回写登记册对应行。
- **验证**：复比对冲突数 = 0 或全部并列标注。
- **回滚**：从 `.bak` 恢复。

## SOP-02 信息重复冗余（C02）

- **触发**：归一化相似度 ≥ 0.9 且无增量。
- **动作**：保留权威源（更高层级 / 更早基线 / 更完整），其余改为一行引用（如「见《报告名》第 N 节」）或删除；同类段落合并。
- **执行**：编辑相关文件；若删除，确认无独有信息。
- **验证**：R-03 ≤ 5%；被删段落无独有信息。
- **回滚**：从 `.bak` 恢复。

## SOP-03 逻辑断层（C03）

- **触发**：结论缺前提 / 证据链断裂。
- **动作**：补桥接段落或补证据；无法补则结论降级为「待核实」并移入待复核清单。
- **执行**：编辑报告对应节。
- **验证**：L-04 ≥ 95%。
- **回滚**：从 `.bak` 恢复。

## SOP-04 内容归属错误（C04）

- **触发**：报告在业务目录外 / 内容主题不符。
- **动作**：
  1. 工具判定：`python engine/tools/classify_reports.py --apply --unknown-warn`。
  2. LLM 判定：先 `.bak` 备份，再移动到新业务线 `reports/`，并更新索引 / 导航 / `reader.html` 引用。
- **验证**：R-01 = 100%；`check_links.py` 无新增断链；`build_index.py` / `build_hub.py` 重新生成。
- **回滚**：从 `.bak` 恢复并还原引用。

## SOP-05 信息缺失（C05）

- **触发**：必填字段空 / 必填节缺 / 来源缺 / 登记册指标未覆盖。
- **动作**：能补则补；不能补则标「未核验」或「暂无数据」，写入待复核清单。**严禁编造**。
- **执行**：编辑报告 / 登记册；登记册回写遵循「增量另存」纪律。
- **验证**：必填字段完整率 100%；待复核清单已记录。
- **回滚**：从 `.bak` 恢复。

## SOP-06 表述矛盾（C06）

- **触发**：同报告内前后表述冲突。
- **动作**：复核原始来源，修正错误表述；在报告「已修正事实清单」追加一条（格式：`❌ 不得再称"…"——正确结论为…。[Source: URL, 年份]`）。
- **执行**：编辑报告。
- **验证**：矛盾数 = 0；已修正事实清单已续写。
- **回滚**：从 `.bak` 恢复。

## SOP-07 来源缺失 / 断头数字（C07）

- **触发**：数值无来源 / 来源不可达 / 媒体转述未标注。
- **动作**：补来源；无法补则标「需核实原文」或删除该数值；失效链接修正或替换。
- **执行**：编辑报告；链接修正参考 `check_links.py` 输出。
- **验证**：A-01 ≥ 95%；A-05 = 100%。
- **回滚**：从 `.bak` 恢复。

## SOP-08 口径混用（C08）

- **触发**：同一指标多口径静默择一 / 混用。
- **动作**：按 business-config「术语口径区分」统一表述；多口径并列呈现，不得取均值。
- **执行**：编辑报告；必要时同步 business-config 口径清单。
- **验证**：L-02 = 100%；并列清单与 business-config 一致。
- **回滚**：从 `.bak` 恢复。

## SOP-09 断链 / 断头锚点（C09）

- **触发**：`href` 无对应 `id` / 路径不存在 / 死链。
- **动作**：修正路径 / 锚点；批量迁移用专用路径改写脚本（或手工逐条）；无法修正则移除链接保留文本。
- **验证**：`check_links.py` 退出码 0；R-04 = 0%。
- **回滚**：从 `.bak` 恢复。

## SOP-10 阈值 / 红线不一致（C10）

- **触发**：K / RL 阈值三处不一致。
- **动作**：以 `{{REGISTRY_PATH}}`「信号规则」表为唯一事实源，同步 business-config 第五节与报告；在版本记录留痕。
- **执行**：编辑 business-config + 报告；必要时重算受影响情景。
- **验证**：L-03 = 100%。
- **回滚**：从 `.bak` 恢复。

## SOP-11 结构缺失（C11）

- **触发**：`h2.sec` 节数 < 骨架 / 缺页头导航。
- **动作**：`python engine/tools/compliance_check.py --scaffold <类型ID> [周期]` 取骨架，按模板补齐；不得增删节 / 调顺序。
- **验证**：C-01 ≥ 100%；`compliance_check.py --check` 退出码 0。
- **回滚**：从 `.bak` 恢复。

## SOP-12 术语不一致（C12）

- **触发**：术语多写法 / 与词汇库不符。
- **动作**：以词汇库 `terms.md` 为准统一；词条缺失走 `python engine/vocabulary/script/vocab_tool.py import`，禁止手工改 `terms.md`。
- **验证**：`vocab_tool.py check` 0 错误；全库写法一致。
- **回滚**：从 `.bak` 恢复。

## SOP-13 时效过期（C13）

- **触发**：数据日期超时效 / 未标滞后。
- **动作**：更新数据或显式标注「滞后 N 期」；不得外推 / 补值。
- **执行**：编辑报告；必要时回写登记册。
- **验证**：A-04 ≥ 90%。
- **回滚**：从 `.bak` 恢复。

## SOP-14 格式漂移（C14）

- **触发**：漂移色 / 非 canonical 类名 / 缺 a11y 强制项。
- **动作**：`python engine/tools/restyle_reports.py --files <报告.html> --rename-chart --fix-colors`；补 `.skip-link` / 焦点环 / `prefers-reduced-motion` / `@media print`。
- **验证**：`page_build_check.py` 0 `[E]`；`lint_reports.py` 无错误项。
- **回滚**：从 `.bak` 恢复。

## SOP-15 维度倒置（C15）

- **触发**：`region` 不在 `sector` / `sub_direction` 之前。
- **动作**：修正 `layout.json` 维度声明顺序 + 目录重构；批量改写引用（专用脚本或手工逐条）。
- **验证**：`validate_layout.py` 退出码 0。
- **回滚**：从 `.bak` 恢复；`layout.json` 还原。

## 六、修复记录格式

每次修复写入 `quality-manifest.json` 的 `repairs[]`，并在审计报告中留痕：

```json
{
  "id": "R-2026-11-14-001",
  "scenario": "C10",
  "sop": "SOP-10",
  "severity": "P0",
  "target": "content/economy/dubai/apartment/prompts/business-config.md",
  "finding": "K01 阈值在 business-config 与登记册不一致",
  "action": "以登记册信号规则表为准同步 business-config 第五节",
  "backup": "<target>.bak",
  "verification": "L-03 = 100%",
  "status": "fixed | pending-human-review",
  "timestamp": "2026-11-14T00:00:00+08:00"
}
```
