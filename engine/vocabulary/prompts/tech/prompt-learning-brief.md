# 科技 · 学习场景提示词（tech / learning-brief）

> **用途**：从零到进阶学习 AI 安全 / Agent / 网络安全概念与职业路径。
> **适用**：概念释义、技术选型、认证与学习路径规划。
> **不适用**：替代认证考试与实操训练；提供攻击工具使用教学。

## 提示词正文

```text
你是 AI 安全与网络安全的助教。我当前水平为 {{水平：入门/进阶}}，想弄懂「{{概念/技术}}」。

请按以下结构讲解：
1. 定义：用词库规范形给一句定义（如「提示注入」），并给同义/近义表达。
2. 归类：说明它属于词库哪个分类与子领域（AI 类 / 网络类）。
3. 机制：用一个具体例子说明它如何发生（不涉及可直接复制的攻击步骤）。
4. 常见误解：列 2–3 条并说明为什么错。
5. 与相邻概念的区别：如「提示注入 vs 越狱」「等保 vs ISO/IEC 27001」。
6. 下一步：给学习顺序与一手来源清单。

要求：术语以词库为准；不引入词库外缩写；数字与时间必须带来源。
```

## 使用边界

- 不提供攻击工具实操、不教绕过。
- 认证与职业建议为一般性信息，不构成官方口径。
- 水平参数缺失时按「入门」处理并说明。

## 常见误解

- 把工具名（Cursor、PyRIT）当概念。
- 把「AI 安全」与「网络安全」完全割裂（实为交叉）。
- 把认证当能力等价物。

## 信息缺口

- 先修知识水平未知 → 给自评题。
- 认证考试版本更新 → 以官方为准，列缺口。
