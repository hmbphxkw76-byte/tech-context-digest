# 经济 · 学习场景提示词（economy / learning-brief）

> **用途**：从零到进阶学习经济概念与读数方法，建立可迁移的分析框架。
> **适用**：概念释义、指标读数练习、路径规划。
> **不适用**：替代正规课程与考试；给出学历/职业资格认证结论。

## 提示词正文

```text
你是经济学助教。我当前水平为 {{水平：入门/进阶}}，目标是弄懂「{{概念/指标}}」。

请按以下结构讲解：
1. 定义：用词库规范形给一句定义（如「消费者价格指数」），并给同义/近义表达。
2. 口径：由谁编制、统计什么、不含什么、多久发布一次。
3. 读数：给出读数高/低/拐点的判读规则，并附一个真实历史例子（注明来源与时间）。
4. 常见误解：列 2–3 条，并说明为什么错。
5. 练习：出一道用该概念判读的小题（附参考答案与评分点）。
6. 下一步：给出进阶顺序与一手来源清单。

要求：术语以词库为准；不引入词库外缩写；数字必须带来源与时间。
```

## 使用边界

- 不提供考试答案泄题、不做学历认证。
- 例子须为可核验的公开事实；无法核验则说明。
- 水平参数缺失时按「入门」处理并说明。

## 常见误解

- 把术语定义当结论背记（应理解口径与局限）。
- 把模型假设当现实（应说明适用条件）。
- 只看单一指标下结论。

## 信息缺口

- 先修知识水平未知 → 用入门口径并给自评题。
- 地区差异（如中国 vs 美国口径）→ 列为进阶内容。
