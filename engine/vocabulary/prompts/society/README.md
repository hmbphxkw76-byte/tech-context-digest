## 一、主题定义与使用边界

**定义**：研究社会结构与分层、人口与家庭、社会保障与福利、文化与价值观、城市化与社区、风险与公共危机、媒体与传播。

| 项 | 内容 |
|---|---|
| 覆盖（拟） | 社会结构与分层 / 人口与家庭 / 社会保障与福利 / 文化与价值观 / 城市化与社区 / 风险与公共危机 / 媒体与传播 |
| 不覆盖 | 经济变量（归 `economy`）；政治制度与权力（归 `political`）；国际关系（归 `international`） |
| 结论边界 | 只给框架性说明与可核验信息，不构成心理、法律、医疗个案意见 |
