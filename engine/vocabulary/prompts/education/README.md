## 一、主题定义与使用边界

**定义**：研究教育体系与制度、院校与机构、专业与课程、教育政策法规、评价认证、教育技术、国际教育与终身学习的结构、口径与相互关系。

| 项 | 内容 |
|---|---|
| 覆盖（拟） | 教育体系与制度 / 院校与机构 / 专业与课程 / 教育政策与法规 / 教育评价与认证 / 教育技术与学习科学 / 国际教育 / 终身学习 |
| 不覆盖 | 经济变量本体（归 `economy`）；国际关系与外交（归 `international`）；政治制度（归 `political`） |
| 结论边界 | 只给框架性说明与可核验信息，不构成升学/留学/资格认证个案意见 |
