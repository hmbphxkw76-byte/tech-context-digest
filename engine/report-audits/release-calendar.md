# 发布日历（RELEASE-CALENDAR）

> **依据**：[量化研究体系优化实施方案](quant-system-optimization-plan-2026-11-14.md) 第三节 M2
> **机制**：各来源发布时点、滞后、复审日集中管理；接入 `update_planner.py` 生成待办；发布后 T+N 日内入库，漏采触发告警。
