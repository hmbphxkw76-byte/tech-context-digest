# Triage 标签

> **状态**：现行约定
> **用途**：把 skill 中的五个 canonical triage 角色映射到本仓库 issue tracker 的标签字符串。

| skill 中的角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK Agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提到某个角色（如「打上 AFK-ready triage 标签」）时，使用上表对应的标签字符串。

> 若本仓库实际使用的标签词汇不同，以 tracker 中的实际标签为准并同步更新本表。
