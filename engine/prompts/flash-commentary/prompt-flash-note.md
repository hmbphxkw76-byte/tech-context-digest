# {{REGION}} · {{TOPIC}} · 快评正文提示词（快评·事件点评型 · 泛用版 · 事件触发）

> **用途**：重大事件（数据发布、政策出台、财报披露、突发事件）发生后 72 小时内输出单份快评。泛用版业务提示词：建新业务线时复制本文件至 `{REGION}/{PROPERTY}/prompts/`，替换变量与 TODO 后即可运行。
> **产出**：快评正文（md 源稿 + 同目录自包含 HTML），落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM-DD}}-主题-快评.md`）。命名不在工具链标准正则内，validate 仅 WARN 不阻断，属预期。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../templates/prompt-generic-base.md) × [监测报告通用规范](../../templates/monitoring-common-spec.md) × [快评正文类型模板（快评·事件点评型）](../../templates/flash-commentary/prompt-flash-note-template.md) × 业务专属配置（实例化后为 `./business-config.md`；泛用版暂缺，业务项以 TODO 标注）。冲突时以业务提示词（即本文件实例化版）为准。

## 一、四段式正文结构（固定顺序，不得增删段）

1. **事件摘要**：事件事实（何时、官方发布渠道与 URL、原文关键数据）；只记事实，不解读。
2. **预期对比**：台账预期值 vs 实际值（偏离方向与幅度）；无预期项声明「无可靠预期」；口径提示（与历史可比性）。
3. **初步影响判断**：对业务监测对象的传导方向判断（标「初步判断，待后续报告验证」）；依据 1–3 条；反向情形说明。
4. **后续观察点**：后续盯什么（指标 / 事件 / 时点）；升级条件命中评估（是否触发深度报告 / 期报联动）。

## 二、快评协议要点

1. **读取锚**：读取 `{{BASELINE_REPORT_PATH}}`（机制与框架锚）；业务线同时运行监测期报时，另读取最新期报对齐既有结论。
2. **预期对比**：从 `{{REGISTRY_PATH}}` 读该项登记值，与实际值对比并登记偏离；不虚构共识值。
3. **事后补验**：发布后按机制文档执行事后补验；修正走「已修正事实清单」（格式见通用基座第五节），不静默改稿。

## 三、执行方式（建议）

1. 第一时间回溯官方原文并登记 URL 与发布时间。
2. 按四段式直接成稿，不启动大型研究子代理；外部输入限定单一事实查询。
3. 完成后立即回写预期台账（实际值 + 偏离）并评估升级条件。

## 四、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python engine/tools/md2html.py`）；HTML 须通过 `python engine/tools/lint_reports.py`。
- 快评件按归档保留策略执行；归档不改变事后补验义务。
