# 基线报告类型模板（职业就业调研型）

> **用途**：职业就业调研型业务线**建立期**的报告类型模板。产出首期基线（深度调研）报告与配套指标登记册，作为后续所有周期更新的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定职业就业调研型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与周期更新的差异）

1. **对比锚属性**：基线报告是后续所有周期更新的对比锚，其九节结构、全部已核实结论与口径裁决规则须被后续更新完整继承。
2. **无上期报告**：不读取 `{{PREVIOUS_REPORT_PATH}}`；「已修正事实清单」为空，产生修正后逐条补记（格式见通用基座第五节）。
3. **调研深度文档**：基线为全量深度调研，覆盖业务配置声明的全部调研维度（市场与政策 / 人才供需与薪酬 / 雇主生态 / 岗位技能 / 资质证书 / 落地路径），不得省略为「要点罗列」。
4. **登记册首建**：运行前确认 `{{REGISTRY_PATH}}` 目标路径与格式；运行后从基线报告提取全部监测指标活值回写登记册（每格附 `[来源, 年份]`），prompt 模板内严禁填写活值。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续周期提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

就业调研型报告允许给出**框架性求职路径建议**（定位策略、技能组合、证书路线、谈判要点），但不承诺就业结果、不保证薪资水平、不给出「必过」式断言；所有建议章须标注「建议 / 推断」，与事实数据明确分离。

## 三、报告结构骨架（九节固定顺序）

> 九节固定顺序为本类型通用骨架；业务提示词可细化节标题措辞，但**不得增删节、调整顺序**。已产出基线报告的节标题为该业务线的固化锚，后续报告逐字继承。

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 核心结论（摘要） | 全文浓缩：核心判断（编号条目，每条含数据、口径、来源）+ 关键数字卡 + 调研说明（来源语言规则、时效窗口、推断标注约定）。 |
| 2 | 行业与政策发展趋势 | 政策框架、市场规模与增速（多口径并列不合并）、需求驱动因素、区域内部结构对比、未来展望（标「推断」）。 |
| 3 | 人才供需与薪酬（核心模块） | 人才缺口（供需两侧）+ 薪酬基准（「岗位 × 职级」交叉分层表）+ 生活成本与净薪模型 + 总薪酬模型 + 多源交叉验证（冲突并列）。汇率与计价单位固定声明。 |
| 4 | 雇主与企业类型细分 | 雇主分类总览表 + 重点雇主核实（逐家附来源）+ 行业生态事件更新。未能核实的实体单列标注。 |
| 5 | 岗位技能要求 | 分岗位要求表（经验 / 技能 / 证书 / 样本来源）+ 专项技能深度（框架映射）+ 工具栈与语言要求。基于在招岗位抽样（样本量与来源声明）。 |
| 6 | 行业认可的职业资质与证书 | 核心证书总览表（发证方 / 层级 / 费用 / 认可证据）+ 专项新证动态 + 证书路线图（分阶段）+ 本地考试可用性。 |
| 7 | 就业落地路径建议（结论章） | 签证与居留路径、求职渠道、个人品牌优化、入境实操清单、薪酬谈判要点（均标「建议」，事实与推断分离）。 |
| 8 | 数据可靠性与局限说明 | 口径差异说明、已修正项汇总、未证实 / 待复核清单（逐项给出复核入口）、来源约束执行结果、时间基准声明。 |
| 9 | 参考来源清单 | 按来源分级分组（官方 / 权威组织 / 专业机构 / 媒体 / 岗位样本），完整 URL，逐点可回溯。 |

## 四、指标追踪表（登记册联动）

- 追踪表编号与清单由业务配置定义；基线报告须完整呈现「监测指标 × 优先数据源」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[来源, 年份]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）；本类型默认 md+html 双格式（业务配置可声明例外）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 九节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 全部调研维度 covered，核心数据点逐点附来源
- [ ] 事实与推断分离；建议章标「建议 / 推断」
- [ ] 指标追踪表齐全，登记册已首建并回写
- [ ] 来源语言规则（{{SOURCE_LANGUAGE_RULE}}）执行结果已声明
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、维度调整、追踪表变更、来源清单变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
