# 周期更新类型模板（竞争情报监测型）

> **用途**：竞争情报监测型业务线**运行期**的报告类型模板，覆盖月度（主更新节拍）与事件触发（重大竞品动作升级）两档。以公开来源为依据、以上一期报告与首期基线为对比锚，完成「采集 → 核验 → 矩阵刷新 → 影响提示」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；本文件规定竞争情报监测型周期更新的差异项与方法框架；冲突时以业务提示词为准。

---

## 一、节拍设计（两档）

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 月度 | 主更新节拍：动态矩阵全量刷新 + 档案卡增量修订 | 常规月度窗口 | 完整九节更新版报告（结构逐字继承基线） |
| 事件触发 | 升级更新：命中信号规则时对应模块重点刷新 | 任一信号规则命中 | 月度报告外追加专项更新；未到窗口时在登记册标注「截至本次日期无更新」 |

- **信号触发器**清单由业务配置维护（格式：`事件 → 受影响模块`）；命中即触发对应模块重点更新；无触发则不得为制造变化而虚构变化。
- 重大动作（融资 / 并购 / 换帅 / 定价重构 / 新产品线）须当期核实并升级，不等待月度窗口。

## 二、更新协议

1. **读取锚**：每次运行必须读取 `{{PREVIOUS_REPORT_PATH}}` 与 `{{BASELINE_REPORT_PATH}}`，继承九节结构、口径裁决与全部已核实结论。
2. **已修正事实清单**：逐条继承并在产生修正后追加（格式见通用基座第五节），严禁重新引入已被推翻的说法；无来源不得入清单。
3. **档案库闭环**：运行前从 `{{REGISTRY_PATH}}` 读竞品档案活值 → 逐家核验 → 运行后回写；每期逐项填写「是否更新」，未变动项注明「截至 {{CURRENT_DATE}} 无更新」。
4. **多源交叉验证**：关键动作（定价、产品发布、组织变动）须至少 2 家独立来源确认；单源动作标注「单源待证」。
5. **产出动态变更摘要**：变更摘要至少覆盖全部监测竞品与信号规则状态，置于报告开头或末章之前。

## 三、各模块更新要点框架

业务提示词按以下框架实例化「要动态获取什么」：

- **竞争格局**：份额与集中度口径更新（多口径并列）、新进入者 / 退出者、格局演变判断复核。
- **竞品档案**：产品矩阵与版本、定价与促销、渠道与生态合作、组织与关键人事、招聘动向（间接情报）。
- **动态矩阵**：本期动作逐条登记（编号 + 玩家 + 动作 + 日期 + 来源 URL）；信号规则命中状态。
- **影响提示**：对自身定位的威胁 / 机会提示（标「判断 / 推断」），与事实分离。

## 四、输出与命名（与仓库工具链对齐）

| 节拍 | 文件名（业务目录相对路径） | 版本号 |
|---|---|---|
| 月度 | `reports/{{YYYY-MM}}_monthly.md`（+ 同名 html） | 写入报告内（vYYYY.MM.DD） |
| 事件触发 | 月度报告内专项章节或 `reports/{{YYYY-MM-DD}}-主题.md` 追加件 | 同上 |

- 文件命名遵循仓库统一约定（`engine/tools` 按此识别）；事件触发的追加件命名不在标准正则内，`validate.py` 仅提示 WARN 不阻断，属预期行为。
- 交付格式：md 源稿 + 同目录自包含 HTML（`engine/tools/md2html.py` 同步生成）；HTML 必须通过 `engine/tools/lint_reports.py`（表格标签配对强制）。
- 基线报告常驻 `reports/` 顶层，不进入归档；周期报告按归档保留策略执行。

## 五、执行方式（建议）

1. 按信息渠道并行启动研究子代理（官网与财报 / 招聘与组织 / 应用商店与产品 / 公开社媒与专利），全部限定公开来源、逐点引用 URL。
2. 子代理返回后由主代理读取 `{{PREVIOUS_REPORT_PATH}}` 做差异合并，继承已修正事实清单，应用业务配置的模块更新要点。
3. 冲突信息保留双份引用；无法核实项单列「待复核清单」。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 九节结构与基线逐字一致（顺序、编号不变）
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] 档案库逐家核对并回写登记册；prompt 模板无硬编码活值
- [ ] 关键动作多源确认；单源项已标注
- [ ] 数据变更摘要 + 待复核清单已产出
- [ ] HTML 通过 lint（标签配对）
