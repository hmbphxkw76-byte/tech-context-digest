# 项目论证类型模板（可行性与市场进入型）

> **用途**：可行性与市场进入型业务线**项目制运行期**的报告类型模板。每个新项目（新市场进入、新产品线、新设点）独立成篇，复用基线评估框架与判定标准，完成「框架复核 → 多维论证 → 打分判定 → Go/No-Go」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；本文件规定项目论证的差异项与方法框架；冲突时以业务提示词为准。

---

## 一、节拍设计（项目制）

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 项目论证 | 单个项目一次性论证，范围由业务配置或当期需求定义 | 业务方立项 | 单份可行性论证报告 + 框架档案更新 |
| 项目复盘 | 已决策项目的假设回验（投后 / 实施后复盘） | 项目实施后固定时点（由业务配置规定） | 复盘报告：假设回验 + 判定标准有效性复核 |

- **结构继承**：本报告结构 = 基线九节骨架逐字继承（节标题为该业务线固化锚，不得增删节、调整顺序）。
- 每个项目独立成篇；同一项目内不混入其他项目数据。
- 判定标准与维度权重原则上复用基线；如需调整须在报告中显式声明并说明理由。

## 二、项目协议

1. **读取锚**：每次项目必须读取 `{{BASELINE_REPORT_PATH}}`（评估框架锚）与最近同类项目报告（如有），继承评估维度、判定标准与全部已核实结论。
2. **已修正事实清单**：逐条继承并在产生修正后追加（格式见通用基座第五节），严禁重新引入已被推翻的说法；无来源不得入清单。
3. **框架档案闭环**：项目前从 `{{REGISTRY_PATH}}` 读框架档案 → 复核维度与标准适用性 → 运行后回写（项目结论、假设命中情况、框架修订留痕）。
4. **引用纪律**：市场、规模、政策输入优先引用本仓其他类型报告的最新版（注明来源报告与口径）；无现成报告时专项补充并标注「本项目专项调研」。
5. **产出项目交付包**：报告（含判定打分表）+ 假设清单附录；结论与风险清单同时呈现。

## 三、各模块要点框架

业务提示词按以下框架实例化「要论证什么」：

- **市场可行性**：需求容量（引用 / 专项）、目标客群、竞争强度、进入壁垒。
- **技术与运营**：资源可得性、关键依赖、运营假设清单。
- **财务测算**：投资额、成本与收入假设（逐条附依据）、回收期 / 内部收益率（三情景）。
- **法规合规**：许可与资质清单（引用政策解读，附官方来源）、合规路径与时点。
- **判定**：逐维度打分对照判定标准；Go / No-Go / 有条件 Go；条件清单与验证时点；实施路线图。

## 四、输出与命名（与仓库工具链对齐）

| 节拍 | 文件名（业务目录相对路径） | 版本号 |
|---|---|---|
| 项目论证 | `reports/{{YYYY-MM-DD}}-主题.md`（+ 同名 html） | 写入报告内（vYYYY.MM.DD） |
| 项目复盘 | `reports/{{YYYY-MM-DD}}-主题-复盘.md`（+ 同名 html） | 同上 |

- 项目制命名不在 `engine/tools` 标准正则内，`validate.py` 仅提示 WARN 不阻断，属预期行为。
- 交付格式：md 源稿 + 同目录自包含 HTML（`engine/tools/md2html.py` 同步生成）；HTML 必须通过 `engine/tools/lint_reports.py`（表格标签配对强制）。
- 基线报告常驻 `reports/` 顶层，不进入归档。

## 五、执行方式（建议）

1. 输入收集先行：先盘点可引用的既有类型报告（行业 / 规模 / 政策 / 竞争），缺口项启动专项调研子代理，逐点引用。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 对齐评估框架，继承已修正事实清单，应用业务配置的维度与标准。
3. 财务假设逐条审计；无法核实项单列「待复核清单」，重大未决项存在时结论降级为「有条件 Go」。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 评估维度与判定标准与基线一致，或调整理由已声明
- [ ] Go/No-Go 建议明确，逐项打分；条件清单（如有）完整
- [ ] 财务测算全假设可审计，三情景呈现
- [ ] 引用来源报告与口径注明完整
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] HTML 通过 lint（标签配对）
