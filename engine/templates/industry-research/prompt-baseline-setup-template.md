# 基线报告类型模板（行业深度研究型）

> **用途**：行业深度研究型业务线**建立期**的报告类型模板。产出首期行业全景基线报告与配套研究边界档案（产业链口径、口径裁决、来源清单），作为后续年度刷新的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定行业深度研究型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与年度刷新的差异）

1. **对比锚属性**：基线报告是后续所有年度刷新的对比锚；产业链口径、玩家清单、口径裁决规则须被后续更新完整继承。
2. **无上期报告**：不读取 `{{PREVIOUS_REPORT_PATH}}`；「已修正事实清单」为空，产生修正后逐条补记（格式见通用基座第五节）。
3. **全景深度文档**：覆盖业务配置声明的全部研究维度（产业链 / 规模格局 / 玩家 / 驱动与风险 / 趋势），不得省略为「要点罗列」。
4. **边界档案首建**：运行后建立研究边界档案（行业边界定义、产业链分层口径、玩家清单与入选标准、规模口径清单），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续周期提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

行业研究报告保持**中性全景刻画**，不给投资评级、不出具 Go/No-Go 决策建议（那是投资分析与尽调型、可行性型的边界）；趋势判断一律标「推断」，多口径规模数据并列不合并。

## 三、报告结构骨架（九节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 执行摘要 | 核心判断（编号条目，每条含数据、口径、来源）+ 行业一句话定位 + 趋势方向综述 + 研究说明（边界、口径、时效）。 |
| 2 | 研究范围与方法 | 行业边界定义（含 / 不含清单）；产业链分层口径；研究方法（案头研究 + 专家访谈）；数据时效窗口。 |
| 3 | 产业链图谱 | 上游 / 中游 / 下游全景（各层关键环节、代表方、价值分布）；环节间的传导关系；图谱图示。 |
| 4 | 市场规模与格局 | 基准年规模（多口径并列不合并，逐口径附来源与假设）；增速与结构；集中度指标。只呈现读数，不做预测（预测归规模测算型或本节标「推断」）。 |
| 5 | 头部玩家与竞争格局 | 玩家清单与分层（入选标准）；逐家要点（业务、规模口径、定位，附来源）；格局特征（标「推断」处注明）。 |
| 6 | 驱动因素与风险 | 需求侧 / 供给侧驱动因素（每条附证据）；风险清单（条目式，不给应对建议）。 |
| 7 | 趋势判断（推断） | 趋势方向逐条推导（依据 → 推断 → 反向声音，高亮块至少 2 条）；明确区分「已发生的结构变化」与「前瞻推断」。 |
| 8 | 数据治理与局限 | 来源分级表（按通用基座第四节实例化）；口径冲突案例与裁决；未核验项单列；研究局限（数据缺口、时滞）。 |
| 9 | 参考来源清单 | 按来源分级分组，完整 URL，逐点可回溯。 |

## 四、边界档案与登记册联动

- 玩家清单、口径清单与追踪项由业务配置定义；基线报告须完整呈现「研究维度 × 优先来源」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[来源, 年份]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 九节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 全部研究维度 covered，多口径规模并列不合并
- [ ] 事实与推断分离；趋势节反向声音齐备
- [ ] 无投资评级、无 Go/No-Go 建议（边界执行）
- [ ] 边界档案与登记册已首建并回写
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、行业边界调整、玩家清单变更、口径变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
