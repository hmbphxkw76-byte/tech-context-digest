# 决策仪表盘型 · 基线模板（类型中立）

> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范](../monitoring-common-spec.md) × [信息分层规范](../information-layering-spec.md) × [决策交付规范](../decision-delivery-spec.md) × 本文件 × 业务专属配置。冲突时以业务提示词 ＞ 业务配置 ＞ 本文件 ＞ 决策交付规范 ＞ 信息分层规范 ＞ 通用基座 ＞ 通用规范。
>
> **类型定位**：跨研究线统一决策层。把各研究线的「结论 + 证据强度 + 触发条件 + 反向证据」收敛为标准化决策卡，暴露缺失事实，按阈值触发补缺 / 专题任务。**不占研究编号、不落研究正文**。

---

## 一、运行变量

```
{{REGION}}               = 跨研究线（业务配置固定值）
{{TOPIC}}                = 决策仪表盘
{{CURRENT_DATE}}         = 本次执行日期
{{CADENCE}}              = 季（决策仪表盘按季更新；事件触发可插刷）
{{BASELINE_DATE}}        = 首期基线日期（仅基线期必填）
{{DECISION_CARDS_PATH}}  = 决策卡台账路径（默认 data/processed/economy/insight/decision_cards.json）
{{SLICES_PATH}}          = 场景切片路径（默认 data/processed/economy/insight/scenario_slices.md）
{{PREVIOUS_REPORT_PATH}} = 最近一期决策仪表盘路径（基线期留空）
{{OUTPUT_PATH}}          = 本期报告落盘路径
{{READING_TIME}}         = 本期读数时点（YYYY-MM-DD）
{{REPORT_VERSION}}       = 版本号（仅核心事实修正时升级）
```

> 本类型为跨研究线综合层（`{{SOURCE_STRATEGY}} = synthesis_only`）：不新采外部数据，台账变量由 `{{DECISION_CARDS_PATH}}` / `{{SLICES_PATH}}` 承载；其余框架变量（`{{REGISTRY_PATH}}` / `{{FRESHNESS_PRIORITY}}` / `{{SOURCE_LANGUAGE_RULE}}` / `{{SOURCE_REGISTRY_PATH}}` 等）见通用基座第二节。

## 二、报告骨架（9 节，基线）

1. **决策摘要**：跨线 Top 结论 + 信息充分度分布；仅引用已核验事实 + 部分核验；≤1 屏。
2. **决策卡总表**：按研究线列出决策卡（结论 / 证据强度 / 触发条件 / 反向证据 / 信息充分度）。
3. **证据强度与反向证据**：逐卡展开证据来源与反向证据；冲突读数并列。
4. **触发条件与阈值距离**：可观测触发条件 + 当前阈值距离；信号灯标注「预校准（ex-ante）」。
5. **信息充分度与缺失清单**：可直接决策 / 需补充 X 类信息才可决策；缺失清单指向盲区台账。
6. **行动协议**：按「触发条件 + 阈值 + 责任角色 + 时限 + 可观测验证指标」输出，三档优先级（立即行动 / 持续观察 / 仅记录存档）。
7. **场景切片**：投资决策 / 就业决策 / 政策制定三类切片，只输出该场景所需信息。
8. **盲区与消号进度**：引用盲区台账（P0 类别优先，类别由业务配置定义）。
9. **参考来源与读数时点**：来源清单 + 本期读数时点 + 新增信息统计模块。

---

## 三、必填模块（新报告 `[E]`）

- **新增信息量化模块**：`本期新增 X 条 / 修正 Y 条 / 无变化 Z 条 / 假设核验进度 k/n`。
- **决策卡字段**：结论 / 证据强度（强中弱）/ 触发条件 / 反向证据 / 信息充分度。
- **行动协议五要素**：触发条件 / 阈值 / 责任角色 / 时限 / 验证指标 + 三档优先级。
- **场景切片**：投资 / 就业 / 政策三类。
- **ex-ante 标注**：阈值校准完成前（至 2027-06），信号灯处标「预校准（ex-ante）」。
- **版本治理**：核验 / 收敛型运行不新增版本号，标注「本期读数时点」。
- **信息等级标注**：关键信息标 `已核验 / 部分核验 / 推断 / 假设`。

## 四、决策卡台账格式（data/processed/economy/insight/decision_cards.json）

```json
{
  "schema_version": "1.0",
  "cards": [
    {
      "card_id": "DC-<研究线>-<序号>",
      "line": "研究线 ID",
      "conclusion": "结论",
      "evidence_strength": "强|中|弱",
      "trigger": "触发条件",
      "counter_evidence": "反向证据",
      "sufficiency": "可直接决策|需补充X类信息才可决策",
      "missing": ["缺失信息类"],
      "actions": [
        {"priority": "立即行动|持续观察|仅记录存档", "action": "…", "threshold": "…",
         "role": "责任角色", "deadline": "YYYY-MM-DD", "verify": "验证指标"}
      ]
    }
  ]
}
```
