# 事件触发更新类型模板（投资分析与尽调型）

> **用途**：投资分析与尽调型业务线**运行期**的报告类型模板，覆盖事件触发更新（财报披露、重大事项、估值假设变动后对标的结论的复核）。以上一期报告与首次覆盖报告为对比锚，完成「事件核验 → 假设复核 → 估值更新 → 结论修订」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；本文件规定事件触发更新的差异项与方法框架；冲突时以业务提示词为准。

---

## 一、节拍设计

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 定期复核 | 财报 / 定期数据窗口的常规复核 | 每季度或年度窗口（由业务配置规定） | 完整八节更新版报告（结构逐字继承首次覆盖） |
| 事件触发 | 重大事项（并购 / 管理层变动 / 诉讼 / 政策冲击）触发的结论复核 | 业务配置触发器命中，或重大事项披露后 | 更新版报告或专项修订件；无触发时在登记册标注「截至本次日期无更新」 |

- **触发器**清单由业务配置维护（格式：`事件 → 受影响模块`）；重大事项须当期核实并复核结论，不等待定期窗口。
- 事件核实以官方披露原文（公告、财报、监管文件）为准，媒体转述仅作线索。

## 二、更新协议

1. **读取锚**：每次运行必须读取 `{{PREVIOUS_REPORT_PATH}}` 与 `{{BASELINE_REPORT_PATH}}`，继承八节结构、口径裁决、估值假设与全部已核实结论。
2. **已修正事实清单**：逐条继承并在产生修正后追加（格式见通用基座第五节），严禁重新引入已被推翻的说法；无来源不得入清单。
3. **标的档案闭环**：运行前从 `{{REGISTRY_PATH}}` 读标的档案 → 核验 → 运行后回写（财务序列、假设变更留痕、风险登记更新）。
4. **估值假设纪律**：只修参数与假设，不推翻模型结构（结构变更走重新覆盖）；假设变更逐条留痕（旧值 → 新值 → 依据）。
5. **产出事件影响摘要**：摘要覆盖本次触发事件、受影响假设与结论变化方向，置于报告开头；结论变化（维持 / 上调 / 下调 / 降级为有条件）须显式声明。

## 三、各模块更新要点框架

业务提示词按以下框架实例化「要动态核验什么」：

- **标的概况**：股权与治理变动、关键合同与资质变化。
- **财务与估值**：最新财务序列、估值假设逐条复核（旧值 → 新值 → 依据）、估值区间更新（多方法并列）。
- **风险登记**：新增风险、已缓解风险归档、重大未决事项状态。
- **结论复核**：投资要点逐条对照新证据；情景与敏感性重算；反向声音更新。

## 四、输出与命名（与仓库工具链对齐）

| 节拍 | 文件名（业务目录相对路径） | 版本号 |
|---|---|---|
| 定期复核 | `reports/{{YYYY-Qn}}_quarterly.md` 或 `reports/{{YYYY}}_annual.md`（+ 同名 html，由业务配置规定） | 写入报告内（vYYYY.MM.DD） |
| 事件触发 | `reports/{{YYYY-MM-DD}}-主题.md` 专项修订件 | 同上 |

- 文件命名遵循仓库统一约定（`engine/tools` 按此识别）；专项修订件命名不在标准正则内，`validate.py` 仅提示 WARN 不阻断，属预期行为。
- 交付格式：md 源稿 + 同目录自包含 HTML（`engine/tools/md2html.py` 同步生成）；HTML 必须通过 `engine/tools/lint_reports.py`（表格标签配对强制）。
- 首次覆盖报告常驻 `reports/` 顶层，不进入归档；更新版按归档保留策略执行。

## 五、执行方式（建议）

1. 事件核验先行：以官方披露原文为准完成事件事实登记，再启动财务与估值复核子代理，逐点引用。
2. 主代理读取 `{{PREVIOUS_REPORT_PATH}}` 做差异合并，继承已修正事实清单，应用业务配置的模块更新要点。
3. 非公开信息使用须逐处标注授权依据；无法核实项单列「待复核清单」。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 八节结构与首次覆盖逐字一致（顺序、编号不变）
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] 估值假设变更逐条留痕（旧值 → 新值 → 依据）
- [ ] 结论变化方向显式声明；风险清单与反向声音更新
- [ ] 事件影响摘要 + 待复核清单已产出
- [ ] HTML 通过 lint（标签配对）
