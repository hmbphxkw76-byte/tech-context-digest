# 基线报告类型模板（投资分析与尽调型）

> **用途**：投资分析与尽调型业务线**建立期**的报告类型模板。产出首期标的覆盖报告（首次覆盖）与配套标的档案（估值模型、假设清单、风险登记），作为后续事件触发更新的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定投资分析与尽调型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与事件触发更新的差异）

1. **对比锚属性**：首次覆盖报告是后续所有事件触发更新的对比锚；标的档案结构、估值模型假设与口径裁决规则须被后续更新完整继承。
2. **结论必须明确**：本类型必须给出明确投资结论（评级 / 建议 / 估值区间），不允许「保持中性不表态」；但结论须与完整风险清单并存。
3. **标的档案首建**：运行后建立标的档案（概况、财务序列、估值模型与假设、风险登记、信息渠道清单），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
4. **合规边界**：只使用合法获得的信息（公开资料、授权数据室、管理层授权访谈）；报告须含利益冲突声明；非公开信息的使用规则由业务配置定义并逐处标注。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续周期提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

投资分析报告输出**估值与风险结论**，服务对象为授权决策方；报告须声明「不构成对不特定公众的投资邀约」；估值模型全部假设可审计；无法核实的关键事项在结论前显式披露，重大未决事项存在时结论降级为「有条件结论」。

## 三、报告结构骨架（八节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 投资要点 | 明确结论（评级 / 建议 / 估值区间，编号条目，每条含数据、口径、来源）+ 核心逻辑 3 条 + 关键风险 3 条 + 有条件结论披露。结论先行，不铺垫。 |
| 2 | 标的概况 | 业务结构、股权与治理、历史沿革、关键合同与资质；每项附来源。 |
| 3 | 行业与市场输入 | 引用行业研究 / 规模测算结论（注明来源报告与口径），只取决策相关输入，不重复行业全景。 |
| 4 | 财务分析与估值模型 | 财务序列分析（收入 / 盈利 / 现金流 / 资产负债，附口径）；估值模型（收益法 / 可比法，全假设与参数依据）；估值区间（多方法并列）。 |
| 5 | 风险清单 | 风险登记（逐条：风险 / 触发条件 / 影响量级 / 缓解依赖）；重大未决事项单列；反向声音（高亮块，至少 2 条）。 |
| 6 | 情景与敏感性 | 三情景估值（乐观 / 基准 / 悲观：假设组合 + 估值区间）；关键参数敏感性表。 |
| 7 | 合规与边界 | 信息来源合法性声明、利益冲突声明。 |
| 8 | 参考来源清单 | 按来源分级分组，完整 URL / 文件名，逐点可回溯。 |

## 四、标的档案与登记册联动

- 监测项、估值假设与风险登记由业务配置定义；基线报告须完整呈现「标的监测项 × 信息渠道」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[来源, 时点]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 八节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 结论明确且与风险清单并存；有条件结论（如有）已披露
- [ ] 估值模型全假设可审计；估值区间多方法并列
- [ ] 信息来源合法性声明与利益冲突声明已写入
- [ ] 标的档案与登记册已首建并回写
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、标的清单调整、估值模型变更、合规规则变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
