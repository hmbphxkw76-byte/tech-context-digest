# 基线报告类型模板（消费者·用户调研型）

> **用途**：消费者·用户调研型业务线**建立期**的报告类型模板。产出首期基线调研报告与配套调研设计档案（抽样框、问卷 / 访谈框架、人群画像假设），作为后续专题调研的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定消费者调研型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与专题调研的差异）

1. **对比锚属性**：基线报告是后续所有专题调研的对比锚；调研设计、抽样方案、画像假设与口径裁决规则须被后续更新完整继承。
2. **一手数据为主**：以一手调研（抽样问卷、深访、焦点小组、实测）为核心证据，二手数据仅作背景与交叉验证；无一手数据支撑的结论须标「二手推断」。
3. **设计档案首建**：运行后建立调研设计档案（目标人群定义、抽样框、样本量与配额、问卷 / 提纲框架、伦理与隐私声明），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
4. **样本质量声明**：样本量、抽样方式、回收率、置信水平须完整声明；未达统计显著性的结论须显式标注。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续专题提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

消费者调研报告输出**人群态度、偏好与行为特征**，不输出「市场必然接受」的断言；画像与细分结论标注「假设 / 验证状态」；行动建议标「建议」，与数据发现明确分离。调研须遵守知情同意与隐私保护，不得采集或留存可识别个人身份的敏感信息。

## 三、报告结构骨架（八节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 执行摘要 | 核心发现（编号条目，每条含数据、口径、来源）+ 人群一句话画像 + 行动建议综述 + 调研说明（样本、方法、时效）。 |
| 2 | 调研设计与方法论 | 目标人群定义；抽样框与配额；样本量与统计口径；方法组合（问卷 / 深访 / 焦点小组 / 行为数据）；伦理与隐私声明。 |
| 3 | 人群细分框架 | 细分维度与画像假设（每类画像：特征 / 需求 / 触点 / 假设依据）；假设的验证状态标注。 |
| 4 | 首期调研结果 | 态度与偏好分布（逐项附样本数与占比）；满意度 / NPS 读数（口径声明）；行为特征（购买 / 使用路径）。只呈现发现，不展开建议。 |
| 5 | 交叉分析与细分发现 | 交叉分析表（人群属性 × 态度 / 行为）；细分差异要点；与二手数据的交叉验证（冲突并列）。 |
| 6 | 数据质量与局限 | 样本偏差说明、置信区间与显著性声明、无应答偏差、二手推断项清单。 |
| 7 | 后续调研日历与专题方向 | 调研日历（专题 / 频次 / 方法 / 输出）；优先专题方向建议（标「建议」）。 |
| 8 | 参考来源清单 | 一手调研材料归档说明 + 二手来源按分级分组，完整 URL，逐点可回溯。 |

## 四、设计档案与登记册联动

- 细分维度、调研日历与追踪项由业务配置定义；基线报告须完整呈现「调研追踪项 × 方法」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[数据来源, 采集时间]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 八节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 样本量、抽样方式、回收率、置信水平完整声明
- [ ] 画像假设的验证状态标注完整；事实与建议分离
- [ ] 伦理与隐私声明已写入；无个人可识别敏感信息
- [ ] 设计档案与登记册已首建并回写
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、人群定义调整、方法体系变更、追踪项变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
