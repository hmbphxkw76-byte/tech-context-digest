# 事件触发解读类型模板（政策法规解读型）

> **用途**：政策法规解读型业务线**运行期**的报告类型模板，覆盖事件触发单份解读（新政策 / 修订出台后）与年度台账复盘两档节拍。以官方原文为准、以基线与上期台账为对比锚，完成「原文回溯 → 逐条解读 → 影响评估 → 台账更新」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；本文件规定事件触发解读的差异项与方法框架；冲突时以业务提示词为准。

---

## 一、节拍设计（两档）

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 事件触发解读 | 单份政策解读：新政策 / 修订 / 配套细则出台后启动 | 监测渠道命中（政策发布、征求意见稿、正式生效） | 单份解读报告；政策台账增量更新 |
| 年度台账复盘 | 政策台账全量复核 + 年度监管态势综述 | 每年固定窗口 | 年度复盘报告（`{{YYYY}}_annual.md`）+ 台账年度新版（另存，不覆盖历史） |

- **结构继承**：本报告结构 = 基线九节骨架逐字继承（节标题为该业务线固化锚，不得增删节、调整顺序）。
- **监测触发器**由业务配置维护（格式：`渠道 / 政策名称 → 动作`）；征求意见稿须登记但标注「非最终文本，以正式发布为准」。
- 无触发时不启动新解读，仅在台账标注「截至本次日期无更新」。

## 二、更新协议

1. **读取锚**：每次运行必须读取 `{{BASELINE_REPORT_PATH}}` 与上期解读 / 复盘报告（如有），继承监管框架地图、解读规则与全部已核实结论。
2. **已修正事实清单**：逐条继承并在产生修正后追加（格式见通用基座第五节），严禁重新引入已被推翻的说法；无来源不得入清单。
3. **官方原文铁律**：新政策须先回溯官方原文（公报 / 法规数据库），登记发布与生效日期、官方 URL 后才可进入解读环节；媒体转述仅作线索。
4. **台账闭环**：运行前从 `{{REGISTRY_PATH}}` 读台账 → 增量登记 / 状态变更 → 运行后回写；每期逐项填写「是否更新」，未变动项注明「截至 {{CURRENT_DATE}} 无更新」。
5. **产出政策变更摘要**：摘要覆盖本期新增 / 修订 / 生效 / 废止政策清单及影响方向，置于报告开头。

## 三、各模块要点框架

业务提示词按以下框架实例化「要解读什么」：

- **政策原文**：发布机构、文号、发布与生效日期、适用范围、关键条款摘编（逐条附原文 URL）。
- **逐条解读**：条款含义、与现行制度的衔接（新增 / 修订 / 废止对照）、歧义条款多解并列、官方答问与细则对照。
- **影响评估**：影响对象矩阵增量（政策 × 主体 × 方向 / 量级 / 依据条款）、过渡期与合规时点。
- **应对建议**：合规要点、待明确事项清单（标「建议」，与事实分离）。

## 四、输出与命名（与仓库工具链对齐）

| 节拍 | 文件名（业务目录相对路径） | 版本号 |
|---|---|---|
| 事件触发解读 | `reports/{{YYYY-MM-DD}}-主题.md`（+ 同名 html） | 写入报告内（vYYYY.MM.DD） |
| 年度台账复盘 | `reports/{{YYYY}}_annual.md`（+ 同名 html）+ 台账年度新版 | 同上 |

- 事件触发解读命名不在 `engine/tools` 标准正则内，`validate.py` 仅提示 WARN 不阻断，属预期行为；年度复盘命名与标准正则兼容。
- 交付格式：md 源稿 + 同目录自包含 HTML（`engine/tools/md2html.py` 同步生成）；HTML 必须通过 `engine/tools/lint_reports.py`（表格标签配对强制）。
- 基线报告常驻 `reports/` 顶层，不进入归档；解读件按归档保留策略执行。

## 五、执行方式（建议）

1. 原文回溯先行：先完成官方原文登记（URL、版本日期、文本完整性），再启动逐条解读子代理；解读逐条附条款定位。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 做框架对齐，继承已修正事实清单，应用业务配置的模块要点。
3. 与现行制度冲突的解读须并列新旧对照；无法核实项单列「待复核清单」。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 全部引用回溯官方原文并附 URL；零媒体转述直引
- [ ] 政策台账增量 / 状态变更已回写；prompt 模板无硬编码活值
- [ ] 新旧制度对照完整；歧义条款多解并列
- [ ] 政策变更摘要 + 待复核清单已产出
- [ ] 建议章与事实分离；不构成法律意见声明保留
- [ ] HTML 通过 lint（标签配对）
