# 基线报告类型模板（政策法规解读型）

> **用途**：政策法规解读型业务线**建立期**的报告类型模板。产出首期监管框架基线报告与配套政策台账（法规清单、官方发布渠道、生效时间线、影响对象矩阵），作为后续事件触发解读的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定政策法规解读型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与事件触发解读的差异）

1. **对比锚属性**：基线报告是后续所有事件触发解读的对比锚；监管框架地图、政策台账结构与解读规则须被后续更新完整继承。
2. **官方原文铁律**：一切解读以官方公报、法规数据库、立法记录原文为准；媒体转述仅作线索，须经原文回溯后才可引用；引用逐条附官方原文 URL。
3. **政策台账首建**：运行后建立政策台账（法规清单：名称 / 发布机构 / 发布与生效日期 / 状态 / 官方原文 URL / 影响对象），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
4. **只盯官方文本**：本类型只处理官方文本与官方解读，不采集舆论反应（那是舆情监测型的边界）；政策发布渠道清单须完整登记。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续周期提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

政策解读报告输出**政策文本解读与影响评估**，不构成法律意见；合规应对建议标「建议」，重大合规决策须提示咨询执业法律专业人士；原文有歧义处并列两种以上解读，不静默择一。

## 三、报告结构骨架（九节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 执行摘要 | 核心判断（编号条目，每条含政策、条款、来源）+ 监管态势一句话 + 生效时间线要点 + 解读说明（文本依据、时效）。 |
| 2 | 政策台账与监测机制 | 台账结构（字段定义）；监测节拍（事件触发单份解读 + 年度台账复盘）；官方发布渠道清单（逐渠道附 URL 与更新机制）。 |
| 3 | 监管框架总览 | 现行法规地图（层级：法律 / 法规 / 规章 / 规范性文件，逐项附官方原文 URL）；监管机构职责分工；框架演变脉络。 |
| 4 | 重点政策逐条解读 | 首期重点政策逐条解读（条款摘编 → 解读 → 官方答问 / 配套细则对照）；歧义条款多解并列。 |
| 5 | 影响对象矩阵 | 影响矩阵（政策 × 受影响主体 × 影响方向 / 量级 / 依据条款）；矩阵逐格附条款依据。 |
| 6 | 合规应对建议（建议章） | 合规要点清单、过渡期安排、待明确事项清单（标「建议」，与事实分离）。 |
| 7 | 生效时间线 | 时间线表（政策 / 关键节点 / 日期 / 依据）；待生效与待细则清单。 |
| 8 | 数据治理与局限 | 来源分级表（官方原文为唯一采信层）；文本时效声明（以何时版本为准）；未核验项单列；解读局限。 |
| 9 | 参考来源清单 | 按来源分级分组（官方原文优先），完整 URL，逐点可回溯。 |

## 四、政策台账与登记册联动

- 监测法规清单与发布渠道由业务配置定义；基线报告须完整呈现「监测法规 × 发布渠道 × 状态」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[官方原文 URL, 版本日期]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 九节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 全部引用回溯官方原文并附 URL；零媒体转述直引
- [ ] 影响矩阵逐格附条款依据；歧义条款多解并列
- [ ] 建议章与事实分离；不构成法律意见声明已写入
- [ ] 政策台账已首建并回写；prompt 模板无硬编码活值
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、监测法规清单调整、渠道变更、解读规则变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
