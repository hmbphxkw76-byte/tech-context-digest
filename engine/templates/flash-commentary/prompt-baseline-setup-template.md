# 基线报告类型模板（快评·事件点评型）

> **用途**：快评·事件点评型业务线**建立期**的报告类型模板。产出快评机制基线文档（事件监测日历、预期台账、快评框架模板），作为后续每次快评的对比锚与制度基础。基线期**不出快评正文**，只建机制。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定快评型基线机制文档的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线文档的特殊定位（与快评正文的差异）

1. **机制文档属性**：基线期产出的是**机制文档**（事件日历、预期台账、快评框架），不是首份快评；其结构与规则须被后续所有快评继承。
2. **无上期报告**：不读取 `{{PREVIOUS_REPORT_PATH}}`；「已修正事实清单」为空，产生修正后逐条补记（格式见通用基座第五节）。
3. **预期台账首建**：运行后建立预期台账（事件类型 → 市场共识预期 / 官方目标值 → 登记依据与时效），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
4. **时效底线**：快评的核验底线是「官方发布稿 / 财报原文为准」——即使时间压力最大，也须回溯一手发布物后才可引用；转述信息单源直引为硬性禁止。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本机制文档；后续快评提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

快评输出**快速影响判断**，时效优先于完备性；但判断必须标注「初步判断，待后续报告验证」；单份快评不推翻既有深度结论，只登记偏离信号；升级为深度报告的条件由业务配置定义。

## 三、机制文档结构骨架（八节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 机制摘要 | 监测范围（事件类型清单）、节拍（事件触发 72h 快评）、升级规则概览。 |
| 2 | 事件监测日历 | 定期事件日历（数据发布 / 会议 / 财报窗口：名称 / 频次 / 预计窗口 / 官方发布渠道 URL）；不定期事件类型清单（触发条件 + 信息渠道）。 |
| 3 | 预期台账首建 | 预期登记表（事件类型 → 共识预期 / 官方目标值 → 依据来源 → 更新时效）；无可靠预期的登记「无预期，仅记实际值」。 |
| 4 | 快评框架模板 | 快评正文四段式固定结构（事件摘要 → 预期对比 → 初步影响判断 → 后续观察点）；篇幅上限；时效标准（72h 内，目标时效由业务配置规定）。 |
| 5 | 信号与升级规则 | 偏离信号规则（实际 vs 预期偏离阈值 → 动作）；快评 → 深度报告 / 期报的升级条件；与监测期报的衔接关系。 |
| 6 | 来源与时效治理 | 官方发布渠道清单（逐渠道 URL）；72h 内的核验底线（一手发布物）；单源直引禁令；事后补验流程。 |
| 7 | 交付物与运行方式 | 交付物表（快评件命名、归档规则）；值班 / 触发运行方式。 |
| 8 | 参考来源清单 | 官方发布渠道与预期依据来源，完整 URL，逐点可回溯。 |

## 四、预期台账与登记册联动

- 事件类型与预期登记项由业务配置定义；基线须完整呈现「事件类型 × 预期来源 × 更新时效」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[来源, 时点]`；无可靠预期项注明「无预期」，不虚构共识值。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 八节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 事件监测日历覆盖业务配置声明的全部事件类型
- [ ] 预期台账已首建并回写；无虚构共识值
- [ ] 快评四段式框架、时效标准、升级规则完整登记
- [ ] 核验底线（一手发布物）与单源直引禁令已写入
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、事件类型调整、预期台账变更、升级规则变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线机制文档不得改动；结构变更只影响后续新基线。
