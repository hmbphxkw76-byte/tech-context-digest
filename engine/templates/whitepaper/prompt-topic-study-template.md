# 专题续作类型模板（白皮书·专题深度型）

> **用途**：白皮书·专题深度型业务线**运行期**的报告类型模板，覆盖专题续作（新选题白皮书、年度系列篇、框架修订篇）。以基线框架与品牌规范为锚，完成「选题准入 → 框架复用 / 修订 → 深度论证 → 审校发布」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；本文件规定专题续作的差异项与方法框架；冲突时以业务提示词为准。

---

## 一、节拍设计（选题制）

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 新选题白皮书 | 新主题独立成篇，复用品牌规范与审校标准 | 选题库准入评审通过（标准见业务配置） | 单份白皮书 + 选题档案更新 |
| 年度系列篇 | 已发布白皮书的年度延续（数据更新、观点复判） | 每年固定窗口或框架修订触发 | 系列篇报告（与上年篇对照） |
| 框架修订篇 | 原创框架重大修订 | 基线框架被新证据实质挑战 | 修订篇（新旧框架对照，不静默替换） |

- **结构继承**：本报告结构 = 基线八节骨架逐字继承（节标题为该业务线固化锚，不得增删节、调整顺序）。
- 无准入选题时不启动新白皮书，不得为产出而降低选题标准。
- 系列篇须与上年篇逐节对照；上年观点原文保留，复判结论（维持 / 修正 / 撤回）显式声明。

## 二、续作协议

1. **读取锚**：每次续作必须读取 `{{BASELINE_REPORT_PATH}}` 与最近一篇同系列白皮书（如有），继承原创框架、品牌规范与全部已核实结论。
2. **已修正事实清单**：逐条继承并在产生修正后追加（格式见通用基座第五节），严禁重新引入已被推翻的说法；无来源不得入清单。
3. **选题档案闭环**：续作前从 `{{REGISTRY_PATH}}` 读选题库与审校标准 → 选题准入 → 运行后回写（选题状态、框架修订留痕、系列篇登记）。
4. **事实纪律**：观点可以鲜明，事实论据逐点附来源；新证据挑战既有观点时须显式复判，不静默改口。
5. **产出续作交付包**：报告 + 审校记录；对外发布前须完成基线第 6 节审校清单全部项。

## 三、各模块要点框架

业务提示词按以下框架实例化「要论证什么」：

- **问题与框架**：新选题的问题定义；复用 / 扩展 / 新建原创框架（决策与理由）；与基线框架的关系声明。
- **深度论证**：沿框架逐要素展开，事实论据逐点附来源，推断显式标注。
- **案例佐证**：案例入选标准与逐案例分析（支撑 / 修正框架）。
- **观点复判**（系列篇）：上年观点逐条对照新证据（维持 / 修正 / 撤回 + 依据）；上年原文保留。
- **倡议**：面向受众的行动倡议（标「倡议」），与事实分离。

## 四、输出与命名（与仓库工具链对齐）

| 节拍 | 文件名（业务目录相对路径） | 版本号 |
|---|---|---|
| 新选题白皮书 | `reports/{{YYYY-MM-DD}}-主题.md`（+ 同名 html） | 写入报告内（vYYYY.MM.DD） |
| 年度系列篇 | `reports/{{YYYY}}_annual.md`（+ 同名 html） | 同上 |
| 框架修订篇 | `reports/{{YYYY-MM-DD}}-主题-修订.md`（+ 同名 html） | 同上 |

- 新选题与修订篇命名不在 `engine/tools` 标准正则内，`validate.py` 仅提示 WARN 不阻断，属预期行为；年度系列篇命名与标准正则兼容。
- 交付格式：md 源稿 + 同目录自包含 HTML（`engine/tools/md2html.py` 同步生成）；HTML 必须通过 `engine/tools/lint_reports.py`（表格标签配对强制）。
- 已发布白皮书常驻 `reports/` 顶层，不进入归档；勘误以勘误件形式发布，不改原稿。

## 五、执行方式（建议）

1. 选题准入先行：对照业务配置准入标准评审，通过后按论证模块并行启动研究子代理，事实论据逐点引用。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 与最近同系列篇做框架对齐与差异合并，继承已修正事实清单。
3. 审校清单（品牌与合规）在成稿后集中执行并留痕；无法核实项单列「待复核清单」，重大未决项存在时不发布。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 选题准入通过并留痕；框架复用 / 修订决策显式声明
- [ ] 事实论据逐点附来源；观点与事实分离
- [ ] 系列篇上年观点逐条复判，原文保留
- [ ] 审校清单全部执行并留痕
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] HTML 通过 lint（标签配对）
