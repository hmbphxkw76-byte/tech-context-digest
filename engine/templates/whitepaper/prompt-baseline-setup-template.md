# 基线报告类型模板（白皮书·专题深度型）

> **用途**：白皮书·专题深度型业务线**建立期**的报告类型模板。产出首份白皮书与配套选题与品牌规范档案（选题库、原创框架、对外发布审校标准），作为后续专题续作的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定白皮书型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与专题续作的差异）

1. **对比锚属性**：首份白皮书是后续专题续作的对比锚；原创框架、核心观点与口径裁决规则须被后续专题完整继承或显式修订。
2. **观点属性**：与行业研究的中性全景不同，白皮书**求深求观点**——必须提出原创框架或鲜明主张；但每个事实性论据仍须逐点附来源。
3. **对外发布标准**：白皮书默认为对外发布物；须通过品牌与合规审校（署名规则、数据授权、争议观点的措辞边界），审校标准由业务配置定义。
4. **选题档案首建**：运行后建立选题与品牌规范档案（选题库与准入标准、原创框架登记、审校清单），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续专题提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

白皮书输出**原创观点与倡议**，观点与事实明确分离；事实论据逐点可回溯，观点部分标「本报告观点」；不借白皮书输出投资评级或法律意见（边界归投资尽调型、政策解读型）。

## 三、报告结构骨架（八节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 执行摘要 | 核心观点（编号条目，明确、鲜明、可争论）+ 关键论据一览 + 倡议要点 + 研究说明（范围、方法、时效）。 |
| 2 | 问题定义与研究框架 | 主题问题的定义（为什么值得研究、争议何在）；原创框架 / 模型（图示 + 要素定义）；与既有研究的差异声明。 |
| 3 | 主题深度论证 | 沿原创框架逐要素论证（论据 → 推理 → 小结）；事实论据逐点附来源；推断步骤显式标注。 |
| 4 | 案例佐证 | 案例清单（入选标准）；逐案例（背景 → 做法 → 结果 → 对框架的支撑 / 修正）；案例数据附来源。 |
| 5 | 观点与倡议 | 核心观点重述与边界（不主张什么）；面向受众的行动倡议（标「倡议」）；未来展望（标「推断」）。 |
| 6 | 品牌与合规审校记录 | 审校清单执行结果（署名规则、数据授权、争议措辞边界）；观点与事实分离的自查结论。 |
| 7 | 数据治理与局限 | 来源分级表；自有数据与二手数据的边界声明；研究局限（样本、时效、框架适用范围）。 |
| 8 | 参考来源清单 | 按来源分级分组，完整 URL，逐点可回溯。 |

## 四、选题档案与登记册联动

- 选题库、审校标准与追踪项由业务配置定义；基线报告须完整呈现「核心论据 × 来源」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格活值附 `[来源, 年份]`；未核实项注明「待核实」，不补值、不外推。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 八节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 原创框架明确且登记；与既有研究的差异声明完整
- [ ] 事实论据逐点附来源；观点标「本报告观点」，与事实分离
- [ ] 品牌与合规审校清单已执行并留痕
- [ ] 选题档案与登记册已首建并回写
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：结构变更、原创框架修订、审校标准变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已发布白皮书不得改动（勘误以勘误件形式发布）；结构变更只影响后续新基线。
