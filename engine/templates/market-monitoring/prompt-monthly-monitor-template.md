# 月度报告类型模板（市场指标监测型）

> **用途**：周期性（每月）刷新月度监测简报的类型模板。以一手 / 权威来源为依据、以指标台账为编号骨架、以上一期报告与首期基线为对比锚，完成「核验 → 判定 → 偏离 → 缺口 → 观察」闭环。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范](../monitoring-common-spec.md) × 本文件 × 业务专属配置。质量规则见通用基座与通用规范；月度差异见本文件；冲突时以业务提示词为准。

---

## 一、月度报告的周期特性

1. **轻量闭环**：月度运行以核验与判定为主；无触发器命中时降级为核验 / 收敛型轻运行（触发器清单由业务配置维护，框架见通用基座第六节）。
2. **T+0 / T+1 判定**：按类型模板的发布日历判定规则执行（官方页面依据由业务配置实例化）。与上期同日或仅隔 1 日时，明确写「本期为 T+1 刷新，官方发布窗口未开，价值在于核验、口径澄清与阈值距离」，不得为制造变化而虚构变化。
3. **发布日历判定**：对业务配置「来源优先级」中的官方一手来源，逐项核对其官网最新一期标题与发布日期，判断当期版本归属；判定方法由业务配置实例化。
4. **追踪表**：按业务配置的月度追踪表逐项核对，全部指标填「是否更新」（协议见通用基座第七节）。

## 二、报告结构骨架（8 节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 结论先行 | 第一句给结论（市场状态 + 信号矩阵计数 + 是否翻转）；说明本期性质（T+0 / T+1 / 空窗）与本期价值；要点按业务配置的指标分组展开（每组 1 条）。 |
| 2 | 关键数字卡 | 张数由业务配置规定；每张含指标名、数值（含单位）、统计周期、发布日期、来源简称 + 卡片内行内链接（完整 URL 写在 `href`，不占用表格列）；标注「实际值 / 预测值 F / 计划值」。 |
| 3 | 月度指标逐项对比 | 按业务配置的指标分组逐组呈现；每行：编号、指标、上期值、本期读数、方向、信号 / 阈值距离、来源（机构 · 周期 · 发布日 · 核验状态；不在单元格内书写 URL 全文）。口径冲突并列呈现。触发预警专题时在对应分组下新增「风险预警」小节（六件套见第三节）。 |
| 4 | 信号灯判定 | 先行信号矩阵（项数与口径与基线一致，注明「较上期是否变化」）；信号规则逐条判定（阈值、本期读数、判定、确认进度；阈值取自台账「信号规则」表）。 |
| 5 | 与首期基线的偏离 | 逐项基线值、本期值、偏离度、性质（复核确认 / 修订 / 结构性 / 版本修正 / 无新期）；解释「零偏离」的含义。 |
| 6 | 数据缺口与未核验项 | 编号、缺口项、应为 / 预计时点、本期状态、影响与处理；状态标签：未发布 / 缺席 / 未取得 / 未重算 / 无官方值 / 未核验。 |
| 7 | 下期观察清单 | 8–10 条，带日期与触发条件。 |
| 8 | 台账更新编号与来源 | 更新编号按五类分组（实质修订 / 新增口径记录 / 复核确认 / 未取得（维持上期值）/ 结论不变）；来源清单（级别、机构 / 文件、统计周期、发布日期），不设独立「完整 URL」列，链接按通用规范第 4 节承载。 |

## 三、专题预警框架（触发时启用）

业务配置可定义专题预警（如融资成本类）。触发条件由业务配置规定；触发时必须在对应指标分组下新增「风险预警」小节，包含**六件套**：

1. **预警面板**：距红线距离（多视角：绝对差 / 相对幅度 / 样本均值距红线 / 近期累计变动）。
2. **关键区分**：仪表盘距离 ≠ 风险发生点；说明确认标准（如连续期数）与单次破线的差别。
3. **证据链**（至少覆盖）：趋势斜率、期限结构 / 内部结构、政策约束、成本或利差传导。
4. **传导量化表 + 图**：至少四档情景（当前 / 红线 / 情景档位 / 更高），量化对目标市场的影响；**必须写明全部假设**。
5. **情景分析**：只给可观测触发条件与影响路径；**不赋予概率**（无官方可校准的期货序列时）。
6. **反向校准 + 来源核查表**：每项校准写明「应有权威来源 / 本期核查结果 / 核验状态 / 对预警的影响」；「没有数据」写成可核验的陈述；盲区统一按「方向确定、幅度未知」处理，不做点估计。

---

## 四、渲染要求（月度特化）

- 通用规范第 5 节顶部导航强制；锚点标签与 8 节标题逐字对应。
- 图表数量下限由业务配置规定；每张图符合通用规范第 2 节研报风。
- 高风险表（信号规则逐条判定表、逐项对比表）逐表校验列宽。

---

## 五、质量自检（在通用基座第九节之上追加）

- [ ] 8 节齐全、顺序正确；导航锚点与节标题逐字一致、跳转准确
- [ ] 关键数字卡数值与第 3 节一致；信号计数与第 4 节规则一致
- [ ] 信号判定执行「连续 2 期同向 + 排除失真信号 + 多指数互证」
- [ ] 追踪表全部指标已核对并填「是否更新」
- [ ] 发布日历判定已完成（T+0 / T+1 / 空窗性质明确）
- [ ] 专题预警六件套齐全（如触发）
- [ ] 数据缺口状态标签规范
- [ ] 渲染与排版符合监测报告通用规范
