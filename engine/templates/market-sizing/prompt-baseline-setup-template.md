# 基线报告类型模板（市场规模测算与预测型）

> **用途**：市场规模测算与预测型业务线**建立期**的报告类型模板。产出首期基准测算报告与配套测算模型档案（方法结构、全假设清单、口径底座），作为后续假设刷新与回测的对比锚与制度基础。
>
> **继承声明（四层体系）**：业务提示词 = [通用基座](../prompt-generic-base.md) × [监测报告通用规范（跨类型共享）](../monitoring-common-spec.md) × 本文件 × 业务专属配置（`{地区}/{业务类型}/prompts/business-config.md`）。质量规则见通用基座与通用规范；本文件规定市场规模测算型基线报告的差异项与结构骨架；冲突时以业务提示词为准。

---

## 一、基线报告的特殊定位（与假设刷新的差异）

1. **对比锚属性**：基线报告是后续所有假设刷新与回测的对比锚；模型结构、全假设清单与口径裁决规则须被后续更新完整继承。
2. **模型即核心交付物**：报告的核心产出是**可审计的测算模型**——每个数字可追溯到假设与来源；模型透明度优先于数字精确度。
3. **模型档案首建**：运行后建立模型档案（方法结构、假设清单、参数取值依据、口径底座、回测规则），回写 `{{REGISTRY_PATH}}`；prompt 模板内严禁填写活值。
4. **多口径并列**：官方统计与第三方数据规模口径冲突时并列呈现，不静默合并；选用口径须声明理由。
5. **产出联动**：基线产出后，`{{BASELINE_REPORT_PATH}}` 即指向本报告；后续周期提示词的该变量值保持不变。

## 二、结论边界（本类型的特别声明）

测算与预测结果一律以**区间 + 情景**呈现（乐观 / 基准 / 悲观），不给单一「神数字」；全部预测标注「推断」并附假设；报告只回答「市场有多大、会长多快」，不做投资评级、不出具进入决策建议（边界归投资尽调型、可行性型）。

## 三、报告结构骨架（九节固定顺序）

| 节 | 模块 | 核心定位 / 必填内容 |
|---|---|---|
| 1 | 执行摘要 | 核心判断（编号条目，每条含区间、口径、来源）+ 基准年规模与预测区间一览 + 关键假设综述 + 方法说明。 |
| 2 | 测算方法与模型结构 | 方法选择（自上而下 / 自下而上 / 混合，含选择理由）；模型结构图（输入 → 参数 → 输出）；模型局限声明。 |
| 3 | 口径与数据底座 | 市场定义与边界（含 / 不含清单）；口径底座表（每项数据：口径 / 来源 / 年份 / 采集方式）；口径冲突并列与选用裁决。 |
| 4 | 基准年规模测算 | 分路径测算过程（逐路径：公式 + 参数 + 取值依据 + 来源）；基准年规模（区间）；交叉验证（多路径结果对照）。 |
| 5 | 分段预测与情景分析 | 预测分段（时段 / 分市场）；三情景表（乐观 / 基准 / 悲观：假设组合 + 结果区间）；情景驱动因素说明。全部标「推断」。 |
| 6 | 敏感性分析 | 关键参数敏感性表（参数变动 → 结果变动）；最敏感参数识别；参数取值依据汇总。 |
| 7 | 模型治理 | 假设审计表（每条假设：依据 / 强度 / 失效信号）；回测规则（回测周期、偏差容忍度、校准动作）；模型版本管理。 |
| 8 | 局限声明 | 数据缺口、方法局限、外推风险、时效窗口；反向声音（高亮块，至少 2 条）。 |
| 9 | 参考来源清单 | 按来源分级分组，完整 URL，逐点可回溯。 |

## 四、模型档案与登记册联动

- 假设清单、参数与回测规则由业务配置定义；基线报告须完整呈现「模型参数 × 取值依据」追踪表，运行后逐项回写 `{{REGISTRY_PATH}}`。
- 每格参数附 `[依据, 年份]`；无依据参数注明「估计值 + 估计方法」，不冒充有源数据。

## 五、图表与渲染（基线期）

- 交付格式：Markdown 源稿 + 同目录自包含 HTML（经 `engine/tools/md2html.py` 同步生成）。
- HTML 须通过 `engine/tools/lint_reports.py`：表格标签配对为强制项。
- 基线导航采用简化锚点目录，不强制升级为 `.report-nav`。

## 六、质量自检（在通用基座第九节之上追加）

- [ ] 九节齐全、顺序正确、编号连续；节标题为该业务线固化锚
- [ ] 每个数字可追溯到假设与来源；模型结构图完整
- [ ] 预测全部为区间 + 三情景，无一票式单点结果
- [ ] 多口径并列与选用裁决完整；无投资评级、无进入决策建议
- [ ] 模型档案与登记册已首建并回写
- [ ] HTML 通过 lint（标签配对）

## 七、维护规范

- **修订触发条件**：模型结构变更、市场定义调整、口径变更、回测规则变更、命名规则变更。
- **变更流程**：先改本类型模板 → 同步业务提示词 → 更新版本记录 → 评估该类型全部周期提示词联动。
- **固化保护**：已产出基线报告不得改动；结构变更只影响后续新基线。
