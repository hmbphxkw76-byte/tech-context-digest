# 30 · 复核提示词（second · L3 语义校验）

> 依据：`engine/audit/verification.md` 第四节。对单份报告做语义复核，**每项写下证据**。

## 复核项

| 项 | 口径 | 通过 |
|---|---|---|
| 信息准确性 | 关键数字与登记册/台账/官方来源核对，一致率 ≥99% | 抽样 ≥10 个关键数字 |
| 来源可追溯 | 关键数字来源可追溯率 ≥95%；死链 0 | 逐点 |
| 数据一致性 | 跨章节/跨报告同指标一致率 ≥99%；阈值三处一致率 100% | 逐指标 |
| 表述逻辑 | 结论-证据一致率 ≥95%；事实与推断分离；口径并列不合并 | 逐结论 |

## 执行

1. 逐项核对并记录证据（文件 + 位置 + 具体值）。
2. 发现不合规 → `--decision fix --finding "<描述>"`，状态保持 `in-review`。
3. 全部通过 → `review <report> --stage second --reviewer agent --decision pass --evidence "L3 通过：..."`。

## 纪律

- 禁止无证据断言；禁止「感觉不一致」。
- 不修改正文；内容问题登记后交 `engine/quality/` 修复闭环。
