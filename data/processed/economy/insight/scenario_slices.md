> **定位**：决策仪表盘的三类读者场景切片，只输出该场景所需信息，不重复全量正文。共享事实走 `[FC-…]` 事实卡片与 `data/processed/economy/insight/decision_cards.json` 指针。
> **读数时点**：2026-11-15 ｜ **版本**：v1.0（基线）

## 场景一：投资决策（主场景）

**决策问题**：值不值得进 / 投 / 持。

| 项 | 内容 |
|---|---|
| 结论 | 市场「高位钝化 → 供给延迟型再平衡」，信号结构未翻转；融资成本逼近硬红线（DC-ECO-APT-01） |
| 证据强度 | 中 |
| 触发条件 | K01 3M EIBOR 破 4.50%（距 10.56bp）；K07 价格同比连续 3 月 <−5% |
| 反向证据 | 成交量 −38% 有基数/结构效应；新推盘 9M −64% 供给收缩支撑价格 |
| 估值锚 | cap rate / DCF 由 `valuation.py` 输出区间；Fed 路径为外生输入（三档折现率） |
| 尾部损失 | `stress_test.py` 五情景损失区间（油价突破 / 霍尔木兹关闭 / 资本外流 / LTV 收紧 / 兑现率塌陷） |
| 信息充分度 | 需补充就业、收入、空置、竣工四类 P0 信息才可决策 |
| 立即行动 | 维持融资成本专题六件套监测（责任：研究负责人；时限 2026-12-31） |

## 场景二：就业决策（主场景）

**决策问题**：能不能去 / 怎么去。

| 项 | 内容 |
|---|---|
| 结论 | AI 网安就业为卖方市场，AI 安全是结构性增量主线（DC-AI-SEC-01） |
| 证据强度 | 强 |
| 触发条件 | 87% 企业招聘困难；填补周期 3–6 个月；AI 为最缺技能 41% |
| 反向证据 | 阿化配额影响私企招聘；L1 SOC 或受 AI 自动化挤压（需求上移而非消失） |
| 关键门槛 | 黄金签证基本月薪 ≥30,000 AED；CISSP / ISO 27001 LI / OSCP 最常点名 |
| 薪酬锚 | 资深 AI 安全工程师 55,000–75,000 AED/月（招聘抽样，部分核验）[FC-SEC-006] |
| 信息充分度 | 可直接决策 |
| 立即行动 | 按黄金签证门槛锁定目标（责任：研究负责人；时限 2026-12-31；验证：offer 基本工资） |

## 场景三：政策制定（主场景）

**决策问题**：政策含义与合规应对。

| 项 | 内容 |
|---|---|
| 结论 | 强制合规构成本地市场制度底座，合规能力成为准入放大器（DC-AI-CI-01 / DC-ECO-TRD-01） |
| 证据强度 | 中 |
| 触发条件 | ISR v3.1（13 控制域）强制适用；NCAP 限制未认证 MSSP；EU AI Act 分阶段生效 |
| 反向证据 | 政策原文核验率仅 1/5（G05 已核验，G01–G04 未核验），乘数不可估 |
| 政策乘数 | `policy_multiplier.py`：未核验政策只给 reference_range，不给数值 |
| 影响对象矩阵 | DESC ISR 适用政府实体及处理政府数据的第三方；NCAP 适用关键基础设施 MSSP |
| 信息充分度 | 需补充政策原文核验（G01–G04）才可决策 |
| 持续观察 | 取得官方英文条款页 / PDF 哈希后重算需求情景（责任：数据采集；时限 2026-12-31） |
